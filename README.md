# 🚀 Frontend Development

Добро пожаловать в полный репозиторий курса по фронтенд-разработке. Здесь собраны учебные материалы, примеры кода и требования к проектам.

## 📂 Модули обучения

### 🎨 [Модуль 1: Основы HTML & CSS](./HTML&CSS/)
Изучение разметки, стилизации, Flexbox, адаптивности и основ SEO.
* **Итого:** Адаптивный многостраничный сайт.

### ⚙️ [Модуль 2: JavaScript](./JavaScript/)
Глубокое погружение в логику: от переменных до асинхронных запросов и работы с API.
