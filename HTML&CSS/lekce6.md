# Лекция 6: Формы в HTML, адаптивная верстка и мобильное меню

## 1. Формы в HTML (`<form>`)

### 1.1 Что такое форма?

**Форма** — это основной способ сбора данных от пользователя. Регистрация, авторизация, поиск по сайту, оформление заказа или подписка на рассылку — всё это работает через формы.

**Особенности:**

* Форма упаковывает данные (текст, файлы, галочки) и отправляет их на сервер.
* Сама по себе форма — это «контейнер». Чтобы данные ушли, нужен серверный язык (PHP, Node.js, Python) или специальные сервисы (например, [Formspree](https://formspree.io/)).

### 1.2 Синтаксис и главные атрибуты

Базовый скелет формы:

```html
<form action="/send-data" method="POST">
</form>

```

* **`action`**: URL-адрес сервера, куда отправятся данные.
* **`method`**: Способ отправки данных:
* **`GET`** — данные передаются в адресной строке (подходит для поиска).
* **`POST`** — данные передаются скрыто (подходит для паролей и личных данных).



💥 **Бонус: Сервис для «оживления» формы (Formspree)**

1. Зарегистрируйтесь на [formspree.io](https://formspree.io/).
2. Создайте проект и новую форму.
3. Скопируйте ссылку из поля **Form endpoint** и вставьте её в атрибут `action`.
4. В атрибут `method` обязательно установите значение `POST`.
⚠️ **Важно:** У каждого поля `input` должен быть атрибут `name` — это «имя переменной», по которому сервер поймет, что прислал пользователь (например, `name="username"`).

### 1.3 Основные элементы формы

1. **Тег `<input>`** — это «швейцарский нож» форм. Его функции зависят от атрибута **`type`**:
* `type="text"` — обычная строка;
* `type="number"` — ввод числа (можно задать границы: `min="1" max="10"`);
* `type="tel"` — для номера телефона (вызывает цифровую клавиатуру на смартфонах);
* `type="password"` — скрывает вводимые символы;
* `type="email"` — проверяет наличие символа `@`;
* `type="checkbox"` — независимая «галочка» (например, «Я согласен с условиями»);
* `type="radio" name="gender" value="male"`-  Мужчина;
* `type="radio" name="gender" value="female"` - Женщина - зависимый переключатель (выбор одного из списка).
  ⚠️**Критический момент:** Чтобы выбрать можно было только один вариант, у всех радиокнопок в группе должен быть **одинаковый `name`**;
* `type="date"` - выбор даты;
* `type="file"` - кнопка для загрузки документов с компьютера;
* `type="color"` - полноценная палитра для выбора цвета;
* `type="range" min="0" max="10"` - ползунок, наподобие уровня громкости;

2. **Тег `<label>`** — подпись к полю.
Никогда не оставляйте `input` без `label` (важно для доступности и UX).

**Способы применения:**

* **Явная связь:** Через атрибуты `for` и `id`. Значение `for` у лейбла должно строго совпадать с `id` инпута.

```html
<label for="user_name">Ваше имя:</label>
<input type="text" id="user_name" name="first_name">

```

* **Неявная связь:** `input` вкладывается внутрь `label`. Удобно для простых форм.

```html
<label>
    Email:
    <input type="email" name="email">
</label>

```
📢 Возьмите себе за правило, не зависимо какой тип связи вы используете всегда связывайте их! Неважно, через вложенность или через for/id. Если пользователь не может кликнуть на текст, чтобы активировать поле — это плохой тон в верстке (плохой UX). И помнимте: Атрибут name — не замена id!

3. **Кнопка отправки**
Для отправки данных внутри формы должна быть кнопка с `type="submit"`.

```html
<button type="submit">Отправить данные</button>

```

4. **Дополнительные элементы:**
   * **`<textarea rows="4" cols="40"></textarea>`** - многострочный ввод, используеться для ввода большого объёма текста в формах — когда одной строки мало. Например: комментарии, отзывы, сообщения, описания. rows - колисество строк, cols - ширина;
   * **`<select>`** — выпадающие списки. Делает жёстко фиксированный список вариантов. Пользователь может выбрать только один (или несколько, если стоит multiple) из того, что ты заранее прописал. Нельзя ввести своё значение. Например:
       ```html
          <label for="city">Выберите город:</label>
          <select id="city" name="city" multiple size="4">
              <option value="prague">Прага</option>
              <option value="brno">Брно</option>
              <option value="ostrava">Острава</option>
          </select>
       ```
   * **`<datalist>`** -  работает в паре с обычным `<input>`. Показывает подсказки, но пользователь может ввести любое своё значение. То есть список — это просто рекомендации, а не ограничения. Например:
        ```html
          <label for="city">Введите или выберите город:</label>
          <input list="cities" id="city" name="city">
          <datalist id="cities">
            <option value="Прага">
            <option value="Брно">
            <option value="Острава">
          </datalist>
        ```
    * **`<fieldset>`** - используеться для логической сгруппировки поля формы. Он делает форму понятнее и визуально, и семантически. Например:
        ```html
          <fieldset>
            <legend>Контактные данные</legend>
            <label>Email:
              <input type="email">
            </label>
            <label>Телефон:
              <input type="tel">
            </label>
          </fieldset>
         ```
   * **`Placeholder`** - атрибут placeholder="Текст..." показывает подсказку внутри поля, которая исчезает при вводе;
   * **`Required`** - если добавить этот атрибут, форма не отправится, пока поле пустое;
   * **`Value`** - значение, которое уже вписано в поле или передается на сервер «за кадром». Особенно важно применить в Radio и Checkbox, без него сервис отправки формы пришлет просто слово "on", и не возможно будет понять, какой пол или на что согдасился пользователь;
   * **`minlength / maxlength`** — ограничение по количеству символов.

### 1.4 Псевдоклассы для стилизации

```css
input::placeholder { color: green; font-size: 18px; } /* Стили подсказки */
input:enabled { border: 2px solid green; }           /* Активное поле */
input:disabled { background: #f0f0f0; border-color: gray; } /* Заблокированное */
input:checked { outline: 2px solid orange; }          /* При нвжвтии на чек-бокс */
input:in-range { background-color: #e0ffe0; }        /*  Срабатывает, когда введенное значение находится внутри границ min и max */
input:out-of-range { background-color: #ffe0e0; }    /* Срабатывает, когда введенное значение находится вне заданного диапазона */
input:valid { border-color: blue; }                  /* Верно заполнено */
input:invalid { border-color: red; }                 /* Ошибка в заполнении */
```

## 2. Адаптивная верстка и Медиа-запросы

### 2.1 Мета-тег Viewport

Обязательный тег для мобильной верстки. Без него браузер телефона будет имитировать широкий экран ПК.

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">

```

* `width=device-width` — ширина сайта равна ширине экрана устройства.
* `initial-scale=1.0` — масштаб 100%.

### 2.2 Медиа-запросы (`@media`)

Позволяют применять стили в зависимости от условий (например, ширины экрана).

```css
@media (max-width: 768px) {
    .container { width: 100%; background: lightgray; }
}

```

### 2.3 Тип носителя

`@media screen and (min-width: 400px)`

* **`screen`** — только для экранов (не для печати на бумаге).
* **`print`** — стили для печати (можно скрыть меню и рекламу).
* **`all`** — для всех типов устройств (по умолчанию).

### 2.4 Стратегии верстки

* **Desktop First**: Сначала стили для ПК, затем «ломаем» через `max-width` для мобилок.
* **Mobile First**: Сначала для телефонов, затем расширяем через `min-width` для ПК. **Это современный стандарт.**

## 3. Hamburger-меню (Практика)

Реализация на чистом CSS с помощью **Checkbox Hack**.

**HTML:**

```html
<nav class="navbar">
  <div class="logo">MySite</div>

  <input type="checkbox" id="menu-toggle" class="menu-toggle">
  <label for="menu-toggle" class="hamburger">
    <span></span>
    <span></span>
    <span></span>
  </label>

  <ul class="menu">
    <li><a href="#">Главная</a></li>
    <li><a href="#">О нас</a></li>
    <li><a href="#">Контакты</a></li>
  </ul>
</nav>

```

**CSS:**

```css
/* Десктопные стили */
.menu-toggle, .hamburger { display: none; }
.menu { display: flex; list-style: none; }

/* Мобильные стили */
@media (max-width: 768px) {
  .hamburger { display: flex; flex-direction: column; gap: 5px; cursor: pointer; }
  .hamburger span { width: 30px; height: 4px; background: black; }
  
  .menu {
    display: none; /* Прячем меню */
    position: absolute; top: 60px; left: 0; width: 100%;
    background: #333; flex-direction: column; text-align: center;
  }

  /* МАГИЯ: Если чекбокс нажат — показываем меню */
.menu-toggle:checked ~ .menu {
    display: flex;
}   /* .menu-toggle:checked — "Когда чекбокс нажат..."
      ~ — "...найди соседа, который идет ниже по коду..."
     .menu — "...с классом .menu и примени к нему стили". */
}

```
