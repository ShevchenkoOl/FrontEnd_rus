# Лекция 3: Кнопки, Якорные ссылки и Box Model

## 1. Тег `<button>`

Тег `<button>` используется для создания интерактивных элементов. В отличие от ссылок, кнопки обычно выполняют действие внутри страницы.

**Пример:**

```html
<button type="button" onclick="alert('Привет!')">Нажми меня</button>

```

> **alert** — это встроенная функция JavaScript, которая показывает всплывающее окно с сообщением.

### 1.1 Типы кнопок (`type`):

* **`button`** — обычная кнопка. Сама по себе ничего не делает, используется для запуска скриптов (JS).
* **`submit`** — отправляет данные формы на сервер.
* **`reset`** — сбрасывает все поля формы к начальным значениям.

⚠️ **Важно:** Если атрибут `type` не указан, браузер по умолчанию считает кнопку типом **`submit`**!

### 1.2 Основные атрибуты:

* **`disabled`** — делает кнопку неактивной (серой). Пользователь не может на неё нажать.
* **`autofocus`** — устанавливает фокус на кнопку сразу после загрузки страницы.

---

## 1.3 Стилизация и взаимодействие

### Вид курсора (`cursor`):

Свойство определяет, как выглядит указатель мыши при наведении на элемент:

* `pointer` — «рука» (стандарт для кнопок и ссылок).
* `default` — обычная стрелка.
* `not-allowed` — знак запрета (идеально для `disabled` кнопок).
* `wait` — индикатор загрузки.

### Псевдоклассы:

Позволяют менять стиль элемента в зависимости от состояния:

* **`:hover`** — при наведении мышкой.
* **`:active`** — в момент самого клика (зажатия кнопки).
* **`:focus`** — когда элемент выбран (например, через клавишу Tab).

## 2. Якорные ссылки и переходы

### 2.1 Якорные ссылки (внутри одной страницы)

Позволяют мгновенно переместиться к конкретному блоку на текущей странице. Для этого используется `id` элемента и символ `#`.

```html
<h2 id="contacts">Наши контакты</h2>
<a href="#contacts">Перейти к контактам</a>

```

Чтобы переход не был резким, в CSS добавляется магическое свойство:

```css
html {
  scroll-behavior: smooth; /* Плавная прокрутка */
}

```

### 2.2 Переходы между страницами

Для перехода на другую страницу просто укажите путь к файлу:

```html
<a href="about.html">О нас</a>
<a href="about.html#team">Наша команда</a>

```

## 3. Box Model (Блочная модель) — Часть 1

Любой HTML-элемент браузер видит как прямоугольный «бокс», состоящий из слоев.

### Структура (изнутри наружу):

1. **Content** — сам контент (текст или картинка).
2. **Padding** — внутренний отступ (создает пространство между контентом и рамкой).
3. **Border** — рамка вокруг элемента.
4. **Margin** — внешний отступ (расстояние до соседних элементов).

---

### 3.1 Единицы измерения

* **px** — фиксированные пиксели.
* **%** — процент от ширины родителя.
* **em** — зависит от размера шрифта **родителя**.
* **rem** — зависит от размера шрифта **корня** (`<html>`, обычно 16px).
* **vw / vh** — 1% от ширины или высоты **окна браузера**.

> 📢 **Примечание:** Если `100vw` создает лишнюю горизонтальную прокрутку, используйте `width: 100%`.

---

### 3.2 Управление размером (`box-sizing`)

По умолчанию (`content-box`) свойства `width` и `height` задают размер **только контента**. Паддинги и рамки добавляются сверху, увеличивая реальный размер блока.

**Пример проблемы:**

```css
.box {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
/* Реальный размер в браузере: 200 + 20*2 + 5*2 = 250px */

```

**Решение:**
Использование `border-box` заставляет браузер «вжимать» паддинги и рамки внутрь заданной ширины.

```css
.box {
  box-sizing: border-box; /* Теперь ширина всегда 200px */
}

```

## 4. Сброс стилей браузера (Reset Styles)

Браузеры по умолчанию добавляют свои отступы для `body`, `h1`, `ul`. Чтобы верстка была предсказуемой, профессионалы используют «обнуление» в самом начале CSS-файла:

```css
*,
*::before,
*::after {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

```
