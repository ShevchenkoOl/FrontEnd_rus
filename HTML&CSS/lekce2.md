# Лекция 2: Семантика, Списки и Основы CSS

## 1. Структурные (семантические) теги

Семантические теги сообщают браузеру и поисковикам, какую роль играет контент. Это важно для SEO и доступности (screen readers).

### Основные блоки страницы:

* **`<header>`** — «шапка» сайта (логотип, меню, поиск).
* **`<main>`** — уникальное основное содержимое страницы (используется один раз).
* **`<footer>`** — «подвал» сайта (контакты, копирайт, ссылки на соцсети).
* **`<section>`** — тематический раздел страницы. Используется для больших блоков: «О нас», «Услуги», «Отзывы».
* **`<div>`** — универсальный контейнер без смысловой нагрузки. Используется для группировки мелких элементов и стилизации.

> 💡 **Правило:** Используйте `<section>` только для логически завершенных блоков контента. Если нужно просто обернуть кусок текста для красоты — используйте `<div>`.

## 2. Списки (Lists) в HTML

Списки помогают структурировать связанные элементы (меню, ингредиенты, шаги).

### 2.1 Неупорядоченный список (`<ul>`- аббревиатура от Unordered List)

Используется, когда порядок не важен. Элементы отмечаются маркерами (точками).

```html
<ul>
    <li>Мука</li> /* List Item */
    <li>Сахар</li>
    <li>Яйца</li>
</ul>

```

### 2.2 Упорядоченный список (`<ol>` - аббревиатура от Ordered List)

Используется, когда важна последовательность (рецепты, инструкции).

```html
<ol>
    <li>Разогрейте духовку до 180°C.</li>
    <li>Смешайте ингредиенты.</li>
</ol>

```

### 2.3 Список описаний (`<dl>`)

Используется для пар «термин — определение» (словари, FAQ).

```html
<dl>     /* Description или Definition List */
    <dt>HTML</dt> /* Description Term */
    <dd>Язык разметки веб-страниц.</dd> /* Description Details */
</dl>
```
> 💡 **Примечание:** В нашей работе мы будем использовать `<ul>`, так как это самый распространённый тег.
>     **Правило:** если есть два или более одинаковых элемента по смыслу — используем список.

## 3. Основы CSS

**CSS (Cascading Style Sheets)** — это язык оформления. Мы можем подключать его тремя способами:

1. **Inline:** Атрибут `style="..."` прямо в теге (не рекомендуется).
2. **Internal:** Тег `<style>` внутри `<head>`.
3. **External:** Отдельный файл `.css` (лучший способ).

### Подключение внешнего файла:

Внутри `<head>` вашего HTML-файла:

```html
<link rel="stylesheet" href="styles.css">

```

### Структура правила:

```css
селектор {
  свойство: значение;
}

```

## 3.1 Селекторы и классы

* **По тегу:** Меняет все теги на странице (например, все `p`).
* **По классу:** Самый гибкий способ. В HTML пишем `class="имя"`, в CSS пишем `.имя`.
```html
<p class="success">Регистрация прошла успешно!</p>


.success {
        color: green;
        font-weight: bold;
}
.error {
        color: red;
}

```
---

## 3.2 Цвета в CSS

1. **RGB:** `rgb(255, 0, 0)` — красный.
2. **RGBA:** `rgba(255, 0, 0, 0.5)` — красный с 50% прозрачностью.
3. **HEX:** `#FF0000` — шестнадцатеричный код.

## 3.3 Редактирование текста и списков

| Свойство | Значение | Описание |
| --- | --- | --- |
| **font-size** | 16px, 2rem | Размер шрифта |
| **font-style** | italic | наклон щрифта|
| **font-weight** | bold, 400, 700 | Толщина текста |
| **text-decoration** | none, underline | Оформление (убрать подчеркивание у ссылок) |
| **text-transform** | uppercase, capitalize, lowercase | Регистр, ВСЕ ЗАГЛАВНЫЕ, все буквы маленькие |
| **text-align** | left, center, right, justify | Выравнивание |
| **list-style** | none | Убрать маркер в списках |

```
список ul - list-style-type: disc;    /* ● */
            list-style-type: circle;  /* ○ */
            list-style-type: square;  /* ■ */
            list-style-type: none;    /* без маркеров */
список ol - list-style-type: decimal;     /* 1, 2, 3 */
            list-style-type: lower-alpha; /* a, b, c */
            list-style-type: upper-alpha; /* A, B, C */
            list-style-type: lower-roman; /* i, ii, iii */
            list-style-type: upper-roman; /* I, II, III */
```
**Ссылка на документацию:** [https://www.w3schools.com/css/default.asp](https://www.w3schools.com/css/default.asp)

## 🛠 Практическое задание: Портфолио-визитка

### 🧱 Структура страницы:

1. **Header**: Заголовок `<h1>` с вашим именем, краткое описание "кто я" и ссылка на GitHub.
2. **Main**:
* **Секция «Обо мне»**: Текст, фото (`<img>`) и горизонтальная линия `<hr>`.
* **Секция «Навыки»**: Список `<ul>` с вашими умениями.
* **Секция «План обучения»**: Список `<ol>` с шагами вашего развития в IT.


3. **Footer**: Текст «© 2026, Студент курса Frontend» и ссылка на контакты.

### 🎨 Стилизация (в отдельном CSS файле):

* Измените цвета заголовков и фона секций.
* Настройте шрифты (размер, жирность).
* Стилизуйте изображение (задайте ширину и добавьте рамку `border`).
* Уберите подчеркивание у ссылок и измените их цвет.
