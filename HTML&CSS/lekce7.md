# Лекция 7: CSS Grid Layout — Двумерные сетки

## 1. Повторение: Flexbox vs Grid

Прежде чем нырять в Grid, важно зафиксировать разницу.

* **Flexbox (1D — Одно измерение):** Идеален для выстраивания элементов в **одну линию** (строку или колонку). Мы используем его для навигационных панелей, карточек в ряд или центрирования одного элемента.
* **Grid (2D — Два измерения):** Это полноценная **шахматная доска**. Он позволяет одновременно управлять и строками, и колонками. Идеален для создания каркаса всей страницы (layout), сложных макетов (табличная структура, галереи, дашборды и т. д.).

> **Золотое правило:**
> Если вам нужно выровнять элементы в ряд — берите **Flexbox**.
> Если вам нужно построить сложную структуру всей страницы (сетку) — берите **Grid**.

---

## 2. Основные понятия Grid

Как и во Flexbox, здесь есть **Grid-контейнер** (родитель) и **Grid-элементы** (дети).

```css
.container {
    display: grid; /* Включаем режим сетки */
}

```

### 2.1 Создание колонок и строк

В Grid мы заранее «рисуем» сетку с помощью свойств:

* `grid-template-columns` — задает количество и ширину колонок.
* `grid-template-rows` — задает количество и высоту строк.

**Пример (сетка 3x2):**

```css
.container {
    display: grid;
    grid-template-columns: 200px 200px 200px; /* 3 колонки по 200px */
    grid-template-rows: 150px 150px;           /* 2 строки по 150px */
    gap: 20px;                                 /* Отступы между ячейками */
}

```
>**Примечание:**
    - Если мы выбираем значение grid, то контейнер ведёт себя как обычный блок, то есть занимает всю доступную ширину родителя и всегда начинаеться с новой строки;
    - Если мы выбираем значение inline-grid, то контейнер ведёт себя как строчно-блочный элемент, его ширина - подстраивается под его содержимое (он не растягивается на весь экран сам по себе). Позволяет другим элементам (тексту, кнопкам или другим inline-grid) вставать с ним в одну строку.Используеться если вам нужно создать небольшую сетку внутри текста или выстроить несколько маленьких сеток в один ряд.

Расположение: Следующий за ним элемент всегда начнется с новой строки.
### 2.2 Способы определение колонок/строк
1️⃣ Перечисление вручную (Explicit)
Самый простой и понятный способ, если колонки должны быть разными.
**Единицы измерения:** 
* `px` - в гридах редко используют, потому что они не адаптивны;
* `fr` (Fraction) - «фракция» или часть свободного пространства;
* `%` - относительная величина, размер распредиляеться в процентном соотношении.

```css
/* Три колонки разной ширины */
grid-template-columns: 100px 1fr 200px; 

```

2️⃣ Смешанный тип
Можно комбинировать фиксированные значения и гибкие доли (`fr`).

```css
/* Первая колонка 150px, остальные две делят остаток пространства поровну */
grid-template-columns: 150px 1fr 1fr;

```
3️⃣ Использование функции `repeat()
Когда нам нужно задать несколько столбцов/строк одного размера

```css
/* Три колонки, которые имеют размер 150px */
grid-template-columns: repeat(3, 150px);

```

4️⃣ Функция `minmax()`
Очень крутой способ для адаптивности. Позволяет задать диапазон: «не меньше X, но не больше Y».

```css
/* Три колонки, которые не сжимаются меньше 100px, но растут до 1fr */
grid-template-columns: 150px minmax(100px, 1fr) 150px;

```

5️⃣ Ключевые слова `auto-fill` и `auto-fit`
Это «автопилот» для сетки. Используется внутри `repeat()`, чтобы браузер сам решил, сколько колонок влезет в контейнер.

```css
/* Браузер сам создаст столько колонок по 200px, сколько поместится в ряд */
grid-template-columns: repeat(auto-fill, 200px);

```

6️⃣ Автоматический размер (`auto`)
Колонка подстраивается под размер самого контента (картинки или самого длинного слова в тексте).

```css
/* Боковые колонки по контенту, центральная забирает всё остальное */
grid-template-columns: auto 1fr auto;

```
**Для создание строк используються те самые способы только свойство будет `grid-template-rows`**

---
### 2.3 gap
Это свойство которое задаёт расстояние между строками и колонками в сетке (grid-gap)
Примеры: ```
            gap: 20px - одинаковый отступ между всеми ячейками
                20px 10px - первая величина — между строками, вторая — между колонками.
            row-gap: 15px;
            column-gap: 40px;
        ```
---
### 2.4 Макет именованными областями `grid-template-areas`
Представь, что твоя сетка — это карта. Ты даешь имена разным участкам и говоришь элементам, какую область занять.

**Как это пишется в CSS:**

```css
.grid-container {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-rows: auto 1fr auto;
  
  /* Рисуем макет кавычками: каждая строка — это кавычки */
  grid-template-areas: 
    "header header header"
    "aside  main   sidebar"
    "footer footer footer";
  
  height: 100vh;
}

/* Теперь привязываем элементы к именам */
.my-header  { grid-area: header; background: lightcoral; }
.my-content { grid-area: main;   background: white; }
.my-left    { grid-area: aside;  background: lightblue; }
.my-right   { grid-area: sidebar; background: lightgreen; }
.my-footer  { grid-area: footer; background: lightgray; }

```

**В чем безупречное удобство:** Если тебе нужно поменять мобильную версию, ты просто переписываешь порядок слов в `grid-template-areas`, и блоки сами прыгают на новые места.

### 2.5 Дополнительные свойста
Свойство **`grid-template`** — это мощное сокращение (shorthand), которое позволяет объединить три свойства в одну строку: `grid-template-rows`, `grid-template-columns` и `grid-template-areas`.
Оно делает код компактнее, но требует понимания особого синтаксиса.
**Простой синтаксис (без областей)** Если тебе нужно просто задать строки и колонки, синтаксис выглядит так: **`строки / колонки`**.

```css
.container {
  display: grid;
  /* 2 строки по 100px / 3 колонки по 1fr */
  grid-template: repeat(2, 100px) / repeat(3, 1fr);
}

```
**Продвинутый синтаксис (вместе с `areas`)**
Это самый наглядный способ. Ты буквально «рисуешь» макет, одновременно указывая высоту строк и ширину колонок.

```css
.container {
  display: grid;
  grid-template:
    "header header header" 100px  /* Имя области + высота строки */
    "aside  main   sidebar" 1fr    /* Имя области + высота строки */
    "footer footer footer" 80px   /* Имя области + высота строки */
    / 200px 1fr 200px;            /* Общая ширина колонок после слэша */
}

```

**Разбор этой записи:**

1. **Каждая строка в кавычках** — это названия ячеек (как мы делали в `grid-template-areas`).
2. **Число после кавычек** — это высота именно этой строки (`grid-template-rows`).
3. **Слэш `/` в конце** — отделяет настройки строк от настроек колонок.
4. **Числа после слэша** — это ширина колонок (`grid-template-columns`).

---

### 2.6 Свойства `grid-column` и `grid-row` (Объединение ячеек)
Если мы нехотим создавать разметку с использованием `grid-template`, мы можем нарисавать ее "графическим способом". Как это вынлядит, каждая линия вертикальная дибо горизонтальная имеет свой номер на месте пересичения. Мы это можем увидеть:
    - правая кнопка мышы -> инструменты разроботчика -> ищем раздел Layout -> Grid/Grid Lanes overlay и ставим галочку div.grid-container.
И ыизуально видя куда мы хотим растянуть ячейку, в свойство `grid-column` или `grid-row` записываем значение, то есть номера линий

* **`grid-column: 1 / 3;`** — элемент займет две колонки.
* **`grid-column: span 2;`** — (удобный вариант) просто "растянись на 2 колонки вширь".
* **`grid-row: span 3;`** — растянись на 3 строки вниз.

---

### 2.7 Выравнивание (как во флексах, но для всей сетки)

Гриды тоже умеют двигать контент:

* **`justify-items` / `align-items**` — выравнивает контент **внутри каждой ячейки**.
* **`justify-content` / `align-content**` — двигает **всю сетку целиком** внутри родителя (если сетка меньше контейнера).
