### 🎨 Требования к проекту

#### 1. Стилизация и оформление
- Используйте шрифты, текстовые элементы, изображения и иконки.
- Верстка с помощью **Flexbox**.
- Разрешено использовать **чистый CSS** или **Tailwind CSS**.

#### 2. Адаптивность
- Медиа-запросы для экранов: `1920px`, `1024px`, `768px`, `320px`.
- Реализуйте **гамбургер-меню** для мобильной версии сайта.

#### 3. Интерактивность и динамика
- Добавьте **анимации** элементов.
- Реализуйте **формы** с базовой валидацией.
- Сделайте **модальное окно**, открывающееся по событию пользователя.
