# Лекция 1: Введение в HTML и структура документа

## 1. Что такое HTML?

**HTML (HyperText Markup Language)** — это не язык программирования, а язык разметки. Если проводить аналогию со строительством дома, то HTML — это его каркас (фундамент, стены, проемы для окон и крыша).

* **Гипертекст:** Текст со ссылками, который позволяет мгновенно перемещаться между страницами.
* **Разметка:** Специальные метки (**теги**), которые говорят браузеру: «Это заголовок», «Это картинка», «Это кнопка».
* **Суть:** Браузер не понимает человеческий язык. Он читает HTML-файл и превращает сухой код в визуальный интерфейс.

### Где используется HTML?

1. **Веб-сайты и сервисы:** От Google до локальных интернет-магазинов.
2. **Мобильные приложения:** Многие гибридные приложения используют веб-технологии.
3. **Email-рассылки:** Красивые письма в вашей почте сверстаны на HTML.
4. **Десктопные программы:** VS Code и Discord написаны с применением веб-технологий.

## 1.2 Инструменты разработчика

Для работы нам понадобятся две вещи: «черновик» (редактор) и «просмотрщик» (браузер).

### 1. Редактор кода (IDE)

**IDE (Integrated Development Environment)** — это не просто блокнот, а целый набор инструментов: текстовый редактор, менеджер файлов, терминал и отладчик.

* **Sublime Text:** Очень быстрый и легкий. Идеален для мелких правок.
* **WebStorm:** «Тяжелая артиллерия», невероятно умный, но платный.
* **Vim:** Легендарный редактор, управляемый только с клавиатуры (для профи).
* **Visual Studio Code (VS Code):** **Наш выбор.** Бесплатный, мощный и самый популярный в индустрии.

### 2. Браузер

Мы будем использовать **Google Chrome** или **Microsoft Edge**. У них лучшие «Инструменты разработчика» (**DevTools**), позволяющие «препарировать» любой сайт.

## 1.3 Базовая структура HTML-документа

Создайте файл `index.html`. В VS Code введите `!` и нажмите **Enter** (плагин Emmet). Вы увидите стандартный шаблон:

```html
<!DOCTYPE html> <html lang="ru"> <head>
  <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <link rel="stylesheet" href="style.css"> <title>Моя первая страница</title> </head>
<body>
  <h1>Привет, мир!</h1>
  <p>Это мой первый абзац</p>
</body>
</html>

```

> 💡 **Примечание: Как добавить второй язык?**
> Если внутри статьи встречается фраза на английском, используйте атрибут `lang` для конкретного тега:
> `<p>Фраза на английском: <span lang="en">"Hello World"</span>.</p>`

## 2. Теги и атрибуты

### Что такое тег?

**Тег (tag)** — основной кирпичик HTML. Пишется в угловых скобках `< >`.

* **Парные теги:** имеют открывающий и закрывающий элементы: `<p>Текст</p>`.
* **Одиночные теги:** не требуют закрытия: `<img>`, `<br>`, `<input>`.

### Основные текстовые теги:

* `<h1>`–`<h6>` — заголовки (от самого важного к менее значимому).
* `<p>` — абзац текста.
* `<strong>` — **жирный текст** (важный смысл).
* `<em>` — *курсив* (акцент).
* `<mark>` — эффект маркера (желтый фон).
* `<del>` — ~~перечеркнутый текст~~.
* `<ins>` — подчеркнутый текст (добавленная информация).

---

### 2.1 Атрибуты — настройки тегов

Атрибуты дают тегам дополнительные возможности.

**1. Ссылки: тег `<a>**`

* `<a href="https://google.com" target="_blank">Открыть Google</a>` — ссылка в новом окне.
* `<a href="mailto:test@gmail.com">Написать письмо</a>` — запуск почтового клиента.
* `<a href="tel:+420123456789">Позвонить</a>` — вызов номера.

**2. Изображения: тег `<img>**`

* `<img src="image.jpg" alt="Описание картинки">`
* `src` — путь к файлу.
* `alt` — текст, который увидят поисковики или пользователи, если картинка не загрузится.

## 🛠 Практические задания

### Задание №1: Каркас сайта

1. Создайте `index.html`.
2. Задайте `title` страницы: "Мое портфолио".
3. Добавьте заголовок `<h1>`: "Добро пожаловать на мою страницу".
4. Добавьте заголовок `<h2>`: "Обо мне".
5. Напишите два абзаца текста о своих увлечениях.

### Задание №2: Форматирование текста

В одном из созданных абзацев примените:

* Одно слово выделите **жирным** (`<strong>`).
* Одну фразу — *курсивом* (`<em>`).
* Сделайте пометку маркером (`<mark>`).
* Используйте `<del>` для зачеркивания любого слова.

### Задание №3: Медиа и контакты

1. Найдите в интернете любую картинку и добавьте её на страницу через `<img>` (не забудьте `alt`!).
2. В конце страницы создайте новый абзац.
3. Внутри абзаца сделайте две ссылки: одну на ваш Email, вторую на номер телефона.
