# Лекция 13: Библиотека CSS Tailwind

**Библиотека** — это набор готовых инструментов и компонентов, которые ускоряют вёрстку, помогают писать меньше кода вручную и обеспечивают единый стиль и адаптивность (responsive design).

Вместо написания сотен строк CSS, вы используете готовые классы прямо в HTML, например: `bg-blue-500 text-white rounded`.

---

## Часть 1. Способы подключения и первый запуск

Существует три основных способа интеграции библиотек в проект:

### 1. Основные методы подключения

* **CDN (Content Delivery Network)**: Глобальная сеть серверов, отдающая файлы с ближайшего к пользователю узла.
* *Плюсы:* Мгновенный старт.
* *Минусы:* Нельзя менять настройки под проект, нужен постоянный интернет.


* **npx (Node Package eXecute)**: Позволяет запускать пакеты напрямую без предварительной установки. Инструмент скачивает пакет, выполняет его и удаляет после завершения. Требует установленного Node.js на ПК.
* **npm (Node Package Manager)**: Полноценный менеджер для управления зависимостями в сложных проектах (сборка, минификация, кастомные настройки).

### 2. Быстрый старт через CDN (Практика)

Для ознакомления с синтаксисом мы используем самый простой метод.

**Шаг 1: Подключение скрипта в `<head>`:**

```html
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>

```

**Шаг 2: Проверка работы:**

```html
<h1 class="text-3xl font-bold text-blue-600 mt-10">
  The Tailwind 4 is working! 🎉
</h1>

```

### 3. Особенности Tailwind: Preflight

В Tailwind не нужно вручную сбрасывать стили (`* {margin: 0}`). Библиотека включает **Preflight** — встроенный CSS-reset на базе **Normalize.css**. Он уравнивает поведение элементов в разных браузерах, исправляя их различия.

## Часть 2. Классический способ: Установка через npm

Для профессиональной разработки, оптимизации веса сайта и доступа к расширенным настройкам необходимо использовать **npm**.

### 🛠 Что должно быть на ПК

Для работы этим способом у вас в обязательном порядке должны быть установлены:

1. **Node.js** (включает в себя npm).
2. **Скачать можно здесь:** [nodejs.org](https://nodejs.org/)

### Алгоритм установки Tailwind CLI:

1. **Установка пакетов:** В терминале вводим `npm install tailwindcss @tailwindcss/cli`.
2. **Создание входного файла:** Создаем файл `input.css` и добавляем в него директиву `@import "tailwindcss";`.
3. **Запуск компиляции:**
```bash
npx @tailwindcss/cli -i ./input.css -o ./output.css --watch
```

*Команда будет следить за изменениями и автоматически генерировать готовый `output.css`*.

### Понимаем структуру файлов проекта:

* **node_modules/**: Папка со всеми модулями, которые использует npm.
* **package.json**: «Паспорт» проекта. Описывает настройки и необходимые пакеты.
* **package-lock.json**: Точная «заморозка» версий всех установленных зависимостей.
* **output.css**: Скомпилированный файл, который мы подключаем в HTML через `<link>`.

## Часть 3. Синтаксис и возможности Tailwind

### 🎨 Работа с цветом и прозрачностью

Вы можете использовать как стандартные цвета, так и произвольные значения в квадратных скобках:

* **HEX:** `bg-[#ff5733]/50` (где `/50` — прозрачность 50%).
* **RGB/HSL:** `bg-[rgb(120,220,100,0.5)]` или `bg-[hsl(200,70%,50%)]`.

### ✨ Анимации и взаимодействие

* **Готовые анимации:** `animate-bounce` (прыжок), `animate-spin` (вращение), `animate-pulse` (пульсация).
* **Псевдоклассы:** `hover:scale-110` (увеличение при наведении).
* **Градиенты:** `bg-gradient-to-r from-blue-500 via-purple-500 to-pink-500`.

### 📱 Респонсивный дизайн (Адаптивность)

Tailwind использует мобильно-ориентированный подход:

* `w-16 md:w-32 lg:w-48` — ширина меняется в зависимости от размера экрана.
* Кастомные брейкпоинты: `max-[540px]:text-[16px]`.

## Часть 4. Работа с GitHub и Командная разработка

При отправке проекта на GitHub **никогда** не загружайте папку `node_modules` и `output.css`.
Создайте файл **.gitignore** и добавьте туда:

```text
.vscode/
node_modules/
output.css

```

**При клонировании чужого проекта выполните команды в терминале:**

1. `npm install` — установит все зависимости из файла `package.json`.
2. `npm run dev` (или команда запуска CLI) — соберет ваш CSS.

### 📚 Полезные ресурсы по Tailwind CSS

* **[Официальная документация Tailwind CSS](https://tailwindcss.com/docs)** — Самый важный ресурс. Поиск по документации работает мгновенно: просто нажми `Ctrl + K` и введи нужное свойство (например, "margin" или "grid").
* **[Tailwind Play](https://play.tailwindcss.com/)** — Официальная онлайн-песочница. Идеально подходит, чтобы быстро потестить классы или поделиться куском кода с кем-то, не создавая проект на компьютере.
* **[Heroicons](https://heroicons.com/)** — Набор бесплатных иконок от создателей Tailwind. Они идеально сочетаются со стилистикой библиотеки и легко настраиваются через классы (цвет, размер).
* **[Tailwind Components](https://tailwindcomponents.com/)** — Огромный репозиторий бесплатных компонентов (кнопки, формы, карточки), созданных сообществом. Можно подсмотреть интересные решения или скопировать готовую верстку.
* **[Flowbite](https://flowbite.com/)** — Популярная библиотека интерактивных компонентов на базе Tailwind (модальные окна, выпадающие списки, табы). Есть как бесплатная, так и платная версии.
* **[HyperUI](https://www.hyperui.dev/)** — Коллекция чистых и современных Open Source компонентов. Очень удобно для быстрого прототипирования интерфейсов.
* **[Tailwind CSS IntelliSense (VS Code Extension)](https://marketplace.visualstudio.com/items?itemName=bradlc.vscode-tailwindcss)** — Обязательное расширение для VS Code. Оно добавляет автодополнение классов, подсказки по цветам и размерам прямо при написании кода.
