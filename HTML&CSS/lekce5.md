# Лекция 5: Позиционирование элементов в HTML & CSS

Когда мы создаём веб-страницы, важно не только содержание, но и то, как элементы располагаются на экране. Иногда достаточно стандартного потока документа, когда элементы идут один за другим. Но чаще всего нам нужно управлять положением блоков:

* Ставить меню в углу;
* Фиксировать шапку при прокрутке;
* Накладывать элементы друг на друга и т.д.

Для этого в CSS есть свойство **`position`**, которое определяет, как браузер рассчитывает координаты элемента и относительно чего он его позиционирует.

---

## 1. Основные значения position

### 1.1 static (по умолчанию)

Это значение по умолчанию у всех элементов.

* Элемент располагается в общем потоке страницы (как идёт HTML — так и отображается).
* Координаты (`top`, `left`, `right`, `bottom`) **не работают**.

**Пример:**

```css
div {
    position: static; /* можно даже не указывать */
}

```

### 1.2 relative (относительное)

Элемент остается в нормальном потоке документа, но получает возможность смещаться относительно своего исходного местоположения.

Для его позиционирования мы можем задать ему четыре направления:

* ⬆️ **`top`** — расстояние от верхнего края того места, где элемент должен был быть изначально.
* ⬅️ **`left`** — расстояние от левого края его «родного» места.
* ⬇️ **`bottom`** — расстояние от нижнего края его «родного» места (толкает вверх).
* ➡️ **`right`** — расстояние от правого края его «родного» места (толкает влево).

> 📢 **Примечание:** Если одновременно задать `left` и `right`, свойство `right` будет проигнорировано. Браузер выберет `left`. То же самое с `top` и `bottom` — приоритет обычно у `top`.

⚠️ **Важно:** Место, которое элемент занимал изначально, **сохраняется за ним**. Другие элементы не подтягиваются на его место.

**Главная фишка:** `relative` часто используют как **"якорь"** (родительский контейнер) для элементов с `position: absolute`.

**Пример:**

```html
<div style="position: relative; background-color: aquamarine; width: 400px; height: 400px; margin-left: 250px">
    <div style="position: absolute; background-color: rgb(12, 85, 241); width: 50px; height: 50px; bottom: 0; right: 0;"></div>
</div>

```

---

### 1.3 absolute (абсолютное)

Элемент полностью вырывается из нормального потока документа.

* **Как это работает:** Он больше не занимает места на странице, и соседние элементы смыкаются, будто его и не было.
* **Относительно чего:** Позиционируется относительно ближайшего родителя, у которого `position` отлично от `static`. Если такого родителя нет, он привязывается к границам окна браузера (`<html>`).

📢 **Где используется:**

* Иконки поверх картинок;
* Всплывающие подсказки;
* Кнопки закрытия в углах модальных окон.

**Пример: «Потерянная иконка»**

```html
<div class="card">
    <div class="heart">❤</div>
    <p>Товар месяца</p>
</div>

```

```css
.card {
    width: 200px;
    height: 200px;
    background: #f0f0f0;
    margin: 100px;
    position: relative; /* Обязательно! Чтобы иконка не улетела в угол экрана */
}

.heart {
    position: absolute;
    top: 10px;
    right: 10px;
    color: red;
    font-size: 24px;
}

```

---

### 1.4 fixed (фиксированное)

Элемент "вылетает" из потока и приклеивается к определенной точке экрана (**viewport**).

* **Как это работает:** При прокрутке страницы элемент остается на месте.

📢 **Применение:** Шапки сайтов (`header`), кнопки "Наверх", виджеты чатов.

**Пример:**

```css
.header {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
    height: 60px;
    background-color: #333;
    z-index: 1000; /* Чтобы быть поверх контента */
}

.content {
    margin-top: 80px; /* Отступ, чтобы зафиксированная шапка не закрыла текст */
}

```

---

### 1.5 sticky (липкое)

Это гибрид `relative` и `fixed`.

* **Как это работает:** Элемент ведет себя как `relative`, пока не достигнет указанной границы (например, `top: 0`), после чего он "залипает" и ведет себя как `fixed`, пока не закончится его родительский контейнер.

**Пример (заголовки в списке):**

```css
h2 {
    position: sticky;
    top: 0;
    background: #f1f1f1;
    padding: 10px;
}

```

---

## 2. Слойность и z-index

Когда элементы накладываются друг на друга, нам нужно решить, какой из них будет сверху.
Для этого используется свойство **`z-index`**:

* Работает только для позиционированных элементов (где `position` **не** `static`).
* Чем выше число, тем "ближе" к пользователю элемент.
* По умолчанию элементы, которые идут в HTML ниже, перекрывают те, что выше.

```css
.modal {
    position: fixed;
    z-index: 100; /* Будет поверх всего контента */
}

```

---

## 3. Свойство overflow (Переполнение)

`overflow` решает, что делать, если контент не влезает в границы блока.

### Основные значения:

* **`visible`** (по умолчанию): Контент вываливается наружу.
* **`hidden`**: Всё, что не влезло — обрезается. 📢 *Это значение отключает `sticky` у вложенных элементов.*
* **`scroll`**: Всегда добавляет полосы прокрутки.
* **`auto`**: Скролл появляется только тогда, когда контента слишком много.

**Разделение по осям:**

* `overflow-x: auto;` — горизонтальная прокрутка.
* `overflow-y: scroll;` — вертикальная прокрутка.

---

### 💡 Лайфхак: Стилизация скроллбара

Стандартные полосы прокрутки можно изменить под дизайн сайта:

* `::-webkit-scrollbar` — ширина всей дорожки.
* `::-webkit-scrollbar-thumb` — сам "бегунок" (за который тянем).
* `::-webkit-scrollbar-track` — фон дорожки.

**Пример:**

```css
.scroll-block {
    height: 300px;
    overflow-y: auto;
}

.scroll-block::-webkit-scrollbar {
    width: 8px;
}

.scroll-block::-webkit-scrollbar-track {
    background: #f1f1f1;
    border-radius: 10px;
}

.scroll-block::-webkit-scrollbar-thumb {
    background: #0c55f1;
    border-radius: 10px;
}

.scroll-block::-webkit-scrollbar-thumb:hover {
    background: #0944c2;
}

```

⚠️ **Помните:** На мобильных устройствах (iOS/Android) кастомные скроллбары часто скрыты системой и появляются только при касании.

### ✅ Итоги лекции 5: Что мы теперь умеем

* **Разбираться в типах позиционирования:**
* `static` — стандартный поток.
* `relative` — сдвиг без потери места в потоке (идеальный "якорь" для вложенных элементов).
* `absolute` — полная свобода перемещения относительно ближайшего родителя с позицией.
* `fixed` — фиксация элемента относительно экрана (шапки, кнопки "вверх").
* `sticky` — "липкий" эффект при скролле.


* **Управлять слоями:** Использовать `z-index`, чтобы определять, какой элемент будет находиться сверху.
* **Контролировать переполнение:** С помощью `overflow` (hidden, scroll, auto) решать, что делать с контентом, который не помещается в блок.
* **Стилизовать скроллбар:** Делать скучные полосы прокрутки частью уникального дизайна.
