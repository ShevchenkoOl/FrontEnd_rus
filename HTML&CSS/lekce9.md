# Лекция 9: Векторная графика, SVG-документы, SVG-спрайты, `<iframe>`
## 1. Векторные изображения

На прошлом занятии мы разобрали, что изображения делятся на два основных вида:

1. 🧩 **Растровые изображения** (состоят из пикселей).
2. 🧭 **Векторные изображения**.

**Векторная графика** состоит не из точек, а из линий, точек и фигур, описанных математически.

### Особенности:

* ✅ **Бесконечное масштабирование:** качество не теряется при любом увеличении.
* ✅ **Маленький размер файла:** идеален для простых форм.
* ❌ **Не подходит для фото:** плохо передает сложные цветовые переходы и реалистичные текстуры.
* **Форматы:** `.svg`, `.eps`, `.ai`.
* **Применение:** иконки, логотипы, схемы, иллюстрации.

---

## 2. Анатомия SVG

Любое векторное изображение состоит из набора фигур (SVG-элементов). Тег `<svg>` является холстом и контейнером одновременно.

```html
<svg width="400" height="300" style="outline: 2px dashed #2a2a2a;">
  </svg>

```

### 2.1 Основные элементы рисования

#### 🟦 Элемент `<rect>` (Прямоугольник)

* `width`, `height` — размеры.
* `fill` — цвет заливки.
* `stroke`, `stroke-width` — цвет и ширина рамки.
* `x`, `y` — смещение от верхнего левого угла холста.
* `rx`, `ry` — скругление углов.

```html
<rect width="250" height="150" fill="tomato" stroke="black" stroke-width="4" x="20" y="20" rx="40" />

```

> **Важно:** В SVG нет понятия `z-index`. Фигуры располагаются в порядке очереди в коде: кто ниже в разметке, тот выше на холсте («слоеный пирог»).

#### 🟢 Элемент `<circle>` (Круг)

* `r` — радиус.
* `cx`, `cy` — координаты центра.

```html
<circle r="100" fill="green" cx="100" cy="100" />

```

#### 🟡 Элемент `<ellipse>` (Эллипс)

* `rx`, `ry` — горизонтальный и вертикальный радиусы.

```html
<ellipse cx="150" cy="100" rx="80" ry="50" fill="blue" />

```

#### ➖ Элемент `<line>` (Линия)

* `x1`, `y1` — точка начала.
* `x2`, `y2` — точка конца.

```html
<line x1="20" y1="50" x2="380" y2="50" stroke="black" stroke-width="16" />

```

#### 🔺 Элемент `<polygon>` (Многоугольник)

* `points` — набор точек (x, y). Фигура автоматически замыкается.

```html
<polygon points="20,20 20,200 200,200 200,20" fill="pink" stroke="black" />

```

#### 🖋 Элемент `<path>` (Путь)

Самый мощный и универсальный элемент. Описывает фигуры любой сложности. Вручную не редактируется — создается в графических редакторах (Figma, Illustrator).

## 3. SVG-документ и viewBox

Файл `.svg` — это текстовый файл.

* **xmlns:** Обязательный атрибут для внешних файлов (пространство имен).
* **viewBox:** Атрибут, определяющий «окно просмотра».
* `viewBox="x y width height"`
* Позволяет масштабировать (приближать/отдалять) изображение внутри холста.

---

## 4. Способы использования SVG на сайте

| Способ | Пример | Особенности |
| --- | --- | --- |
| **Тег `<img>**` | `<img src="icon.svg">` | Просто, кэшируется, но нельзя менять цвет через CSS. |
| **Фон CSS** | `background-image: url(...)` | Удобно для декора, нельзя управлять стилями линий. |
| **Встроенный (Inline)** | `<svg>...</svg>` | Позволяет менять цвета через CSS, но раздувает HTML-код. |
| **Спрайты** | `<use href="sprite.svg#id">` | **Лучший способ:** кэшируется, чисто в HTML, можно менять цвета. |

### Работа со спрайтами

1. Создается файл-библиотека, где каждая иконка обернута в `<symbol id="уникальный-id">`.
2. В HTML вызывается нужная иконка:

```html
<svg class="icon">
    <use href="./images/icons.svg#delete"></use>
</svg>

```

## 5. Оформление через CSS

SVG-элементы имеют свои специфические свойства стилизации, отличные от обычного текста:

```css
.icon {
  fill: #2a2a2a;       /* Цвет заливки */
  fill-opacity: 0.7;   /* Прозрачность заливки */
  stroke: #f44336;     /* Цвет обводки */
  stroke-width: 3px;   /* Ширина обводки */
  stroke-opacity: 0.7; /* Прозрачность обводки */
}

```

### **6. Тег `<iframe>**`

Тег `<iframe>` (inline frame) позволяет встраивать контент с других ресурсов прямо на вашу страницу. Это своего рода «окно», в котором отображается другой HTML-документ.

#### **Основные атрибуты:**

* `src` — путь к странице или ресурсу, который нужно встроить.
* `width` и `height` — ширина и высота фрейма.
* `loading="lazy"` — современный стандарт для отложенной загрузки (улучшает производительность).
* `allowfullscreen` — позволяет разворачивать контент (например, видео) на весь экран.
* `sandbox` — атрибут безопасности, который ограничивает возможности встроенного контента (запрещает запуск скриптов, отправку форм и т.д.).

#### **Пример 1: Встраивание видео с YouTube**

Обычно сервисы сами предоставляют готовый код, но важно понимать его структуру:

```html
<iframe 
  width="560" 
  height="315" 
  src="https://www.youtube.com/embed/dQw4w9WgXcQ" 
  title="YouTube video player" 
  frameborder="0" 
  allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" 
  allowfullscreen>
</iframe>

```

#### **Пример 2: Встраивание Google Карты**

```html
<iframe 
  src="https://www.google.com/maps/embed?pb=!1m18!1m12!1m3!1d2540.66443021111!2d30.5190583!3d50.4473485!2m3!1f0!2f0!3f0!3m2!1i1024!2i768!4f13.1!3m3!1m2!1s0x0%3A0x0!2zNTDCsDI2JzUwLjUiTiAzMMKwMzEnMDguNiJF!5e0!3m2!1sru!2sua!4v1625500000000!5m2!1sru!2sua" 
  width="600" 
  height="450" 
  style="border:0;" 
  allowfullscreen="" 
  loading="lazy">
</iframe>

```

#### **Пример 3: Встраивание PDF**
```html
<iframe 
  src="./documents/manual.pdf" 
  width="100%" 
  height="600px">
</iframe>
```
или с предложеным вариантом для скачивания:
```html
<section>
  <h3>Учебные материалы</h3>
  
  <iframe src="lesson9.pdf" width="100%" height="400px"></iframe>

  <div style="margin-top: 10px;">
    <a href="lesson9.pdf" download class="btn">
      💾 Сохранить PDF на компьютер
    </a>
  </div>
</section>

```
* **`download`** — говорит браузеру не открывать файл, а скачивать.
* **Значение атрибута** (`"Инструкция_по_Grid.pdf"`) — позволяет сразу переименовать файл при сохранении.


> **⚠️ Важно:** Некоторые сайты запрещают встраивать себя в `iframe` из соображений безопасности (используя заголовок `X-Frame-Options`).
