# Лекция 14: Семантика, доступность и оптимизация сайта

## Часть 1. Семантика и доступность (Accessibility)

### 1️⃣ Семантика в HTML

**Семантика** — это использование тегов в соответствии с их смысловым назначением. Семантический код сообщает браузерам, поисковикам и вспомогательным технологиям (Screen Readers), какую роль играет каждый блок контента.

**Как работают Screen Readers (экранные читалки):**
Это программы для слабовидящих людей, которые:

* Сканируют структуру HTML.
* Определяют типы элементов (заголовки, ссылки, навигация).
* Озвучивают их через синтезатор речи.
* *Например:* встретив тег `<nav>`, программа скажет «Навигация», помогая пользователю быстро найти меню.

#### Основные семантические теги:

| Тег | Назначение |
| --- | --- |
| `<header>` | Шапка страницы или раздела. |
| `<main>` | Главное (уникальное) содержимое документа. |
| `<nav>` | Блок навигационных ссылок. |
| `<section>` | Тематический раздел документа. |
| `<article>` | Независимая, законченная единица контента (статья, пост). |
| `<aside>` | Побочный контент (боковая панель, реклама). |
| `<footer>` | «Подвал» страницы или раздела. |

> **Итог:** Используйте `<div>` и `<span>` только тогда, когда нет подходящего по смыслу тега. Семантика критически важна для **SEO** и **доступности**.

### 2️⃣ Доступность (Accessibility)

**Доступность** — это создание интерфейсов, которыми может пользоваться каждый, независимо от физических ограничений.

#### Ключевые инструменты:

1. **ARIA-атрибуты**: Набор атрибутов (`role`, `aria-label`), уточняющих роль элемента.
* `<button aria-label="Закрыть меню">×</button>` — поясняет цель кнопки без видимого текста.
* `<div role="button">Сохранить</div>` — сообщает, что `div` ведет себя как кнопка.


2. **Alt-тексты для изображений**:
* `<img src="logo.png" alt="Логотип компании">` — без `alt` читалка просто произнесет название файла.


3. **Навигация клавиатурой**: Все кнопки и ссылки должны быть доступны через клавишу `Tab`.
* Используйте псевдокласс `:focus-visible` для подсветки активного элемента.


4. **Контрастность**: Текст должен быть легко читаемым на выбранном фоне.

## Часть 2. Оптимизация и производительность

### 1. Оптимизация изображений

**Lazy Loading (Ленивая загрузка)** — загрузка ресурсов только в тот момент, когда пользователь доскроллил до них.

* `<img src="photo.jpg" loading="lazy" alt="...">`
* `loading="lazy"` — экономит трафик и ускоряет первую отрисовку страницы.
* `loading="eager"` — загружает изображение немедленно (для баннеров на первом экране).

### 2. Минификация

Процесс удаления лишних пробелов, комментариев и переносов строк для уменьшения веса файлов.

* **Инструменты:** [HTML Minifier](https://kangax.github.io/html-minifier/), [CSS Minifier](https://www.toptal.com/developers/cssminifier).

## Часть 3. Lighthouse — проверка качества

**Lighthouse** — инструмент в браузере Chrome для аудита сайта.
**Где найти:** `F12` → вкладка `Lighthouse` → `Generate report`.

**Показатели:**

* **Performance**: Скорость загрузки и рендеринга.
* **Accessibility**: Уровень доступности для экранных читалок.
* **Best Practices**: Безопасность (HTTPS), отсутствие устаревших функций.
* **SEO**: Наличие мета-тегов и правильных заголовков.

## Часть 4. Основы SEO и Мета-данные

### 1. Мета-теги в `<head>`

```html
<title>Уроки HTML и CSS для начинающих</title>
<meta name="description" content="Бесплатные уроки по верстке сайтов с нуля.">
<meta name="robots" content="index, follow">

```

* `index, follow`: Робот добавляет страницу в поиск и идет по её ссылкам.
* `noindex, nofollow`: Полный запрет на индексацию.

### 2. Социальные сети (Open Graph)

Позволяет контролировать внешний вид ссылки при репосте в Telegram, Facebook или LinkedIn.

```html
<meta property="og:title" content="Заголовок для соцсетей">
<meta property="og:image" content="https://example.com/preview.jpg">

```

### 3. Микроразметка (Schema.org)

Помогает Google и Bing понимать тип контента (товар, статья, организация). Используется формат **JSON-LD**:

```json
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "EducationalOrganization",
  "name": "IT-Школа"
}
</script>

```

## Часть 5. Дополнительные фишки

1. **Фавиконка**: `<link rel="icon" href="/favicon.ico" type="image/x-icon">`
2. **Стили для печати**:
```css
@media print {
  .no-print { display: none; } /* Скрываем навигацию/рекламу при печати */
  body { color: black; background: white; }
}

```


3. **Ссылка на скачивание**:
* `<a href="contract.pdf" download>Скачать договор</a>` — атрибут `download` инициирует сохранение файла.
