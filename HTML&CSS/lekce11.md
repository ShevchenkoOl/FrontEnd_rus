# Лекция 11: Методологии CSS. Знакомство с БЭМ

**Методология** — это система принципов, правил и подходов для решения определённых задач. В программировании она помогает организовать работу, сделать код понятным, предсказуемым и поддерживаемым.

## 1. Популярные методологии CSS

Существует множество подходов к организации стилей. Каждый из них решает проблему «запутанного кода»:

* **OOCSS** (Object-Oriented CSS) — разделение структуры и оформления.
* **SMACSS** — категоризация стилей на базовые, модульные, макетные и т.д.
* **Atomic CSS** — один класс равен одному CSS-свойству.
* **CSS Modules** — автоматическая изоляция стилей через уникальные имена.
* **BEM (БЭМ)** — Блок, Элемент, Модификатор.

Мы с вами подробно изучим **БЭМ**. Эта методология была разработана в Яндексе и стала стандартом индустрии. Это не просто правила именования классов, а парадигма восприятия интерфейса как набора независимых сущностей (как конструктор LEGO).

---

## 2. Основные понятия БЭМ

### 📦 Блок

Независимый компонент страницы, который имеет смысл сам по себе. Его можно перенести в любую часть проекта без потери функциональности.

* *Примеры:* `.logo`, `.menu`, `.button`, `.card`.
* *Имя:* Отвечает на вопрос **«Что это?»**, а не «Как выглядит?».

### 🧩 Элемент

Составная часть блока, которая не имеет смысла и не может использоваться отдельно от него.

* *Имя:* Всегда начинается с имени блока + два подчеркивания: `блок__элемент`.
* *Примеры:* `.menu__item`, `.button__icon`, `.card__title`.

### 🛠 Модификатор

Дополнительный класс, который изменяет внешний вид или поведение блока/элемента.

* *Имя:* Имя сущности + два дефиса: `сущность--модификатор`.
* *Примеры:* `.button--red`, `.menu__item--active`.

## 3. Глубокое погружение

### 3.1 Блок и вложенность

Блоки можно вкладывать друг в друга. При этом они остаются независимыми.

```html
<header class="page-header">
  <a href="" class="logo"></a>

  <ul class="navigation">
    ...
  </ul>
</header>

```

### 3.2 Элемент и «плоская структура»

Важнейшее правило: **имя класса элемента не должно отражать вложенность в HTML**. Класс всегда состоит только из `блок__элемент`.

**❌ Неправильно (иерархия в имени):** `.nav__item__link`
**✅ Правильно (плоская структура):** `.nav__link`

```html
<article class="product">
  <div class="product__content">
     <a class="product__link" href="">Подробнее</a>
  </div>
</article>

```

### 3.3 Модификатор

Модификатор **никогда** не используется самостоятельно. Он всегда идет в паре с основным классом.

```html
<p class="alert--error">Текст ошибки</p>

<p class="alert alert--error">Текст ошибки</p>

```

## 4. Кнопка-конструктор (Практический пример)

БЭМ позволяет гибко управлять элементами. Если у кнопки иконка может быть как слева, так и справа, мы используем модификаторы для управления отступами:

```css
.button__icon--start { margin-right: 10px; }
.button__icon--end { margin-left: 10px; }

```

Теперь мы просто меняем классы в HTML, и иконка всегда имеет правильный отступ относительно текста.

## 5. Практические задания и решения

### Задача 1: Карточка участника команды

**До:**

```html
<div>
  <img src="user.jpg">
  <h3>Иван Петров</h3>
  <p>Frontend-разработчик</p>
</div>

```

**Решение (БЭМ):**

```html
<div class="team-member">
  <img src="user.jpg" alt="Иван Петров" class="team-member__photo">
  <h3 class="team-member__name">Иван Петров</h3>
  <p class="team-member__role">Frontend-разработчик</p>
</div>

```

### Задача 2: Модальное окно

**Решение (БЭМ):**

```html
<div class="modal">
  <h2 class="modal__title">Подтвердите действие</h2>
  <div class="modal__actions">
    <button class="modal__button modal__button--confirm">Да</button>
    <button class="modal__button modal__button--cancel">Нет</button>
  </div>
</div>

```

### Задача 3: Рефакторинг «грязного» кода

Вместо бессмысленных классов типа `.header`, `.title`, `.blue-text`, мы используем семантику БЭМ:

```html
<article class="card">
  <header class="card__header">
    <h2 class="card__title">О компании</h2>
  </header>
  <div class="card__content">
    <button class="button button--primary">Подробнее</button>
  </div>
</article>

```

## 6. Итоговый проект: TechStore

Ниже представлен пример разметки целой секции магазина, оформленной по всем правилам БЭМ:

```html
<header class="page-header">
  <div class="page-header__container">
    <a href="#" class="logo">TechStore</a>
    <nav class="navigation">
      <ul class="navigation__list">
        <li class="navigation__item">
          <a href="#" class="navigation__link navigation__link--active">Главная</a>
        </li>
      </ul>
    </nav>
  </div>
</header>

<section class="products">
  <article class="product product--featured">
    <img src="laptop.jpg" alt="Ноутбук X100" class="product__image">
    <div class="product__content">
      <h3 class="product__title">Ноутбук X100</h3>
      <div class="product__meta">
        <span class="product__price">₽ 59 990</span>
        <button class="button button--primary">Купить</button>
      </div>
    </div>
  </article>
</section>

```
