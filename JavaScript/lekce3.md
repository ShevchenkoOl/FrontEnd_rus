# Лекция 3: Булевые значения, операторы сравнения и логика в JavaScript

## 1. Тип данных Boolean
**Boolean** — это базовый тип данных в JavaScript, который может принимать только два значения: `true` (истина) или `false` (ложь).

Тип данных Boolean появился в программировании благодаря **Алгебре Буля** — разделу математической логики, созданному английским математиком Джорджем Булем. Эта алгебра изучает высказывания, которые могут иметь только два значения (1 или 0). Эта система легла в основу работы всех компьютеров, электронных схем и условий в программировании.

В классической алгебре Буля существуют логические аксиомы, таблицы истинности и основные операции (конъюнкция, дизъюнкция, отрицание). Однако в JavaScript мы используем только практическую часть — логические значения и операторы, которые помогают управлять ходом программы.

**Для чего используются булевые значения:**
- создание логики программы
- создание условий (ветвлений)
- управление поведением программы (например, циклами)

### ✅ Когда появляется булево значение?
Булево значение возникает в четырёх основных случаях:

1. **При сравнении**
   Любое сравнение двух величин всегда возвращает `true` или `false`.
2. **В логических выражениях**
   Операторы `&&`, `||`, `!` приводят значения к булевому типу:
   ```javascript
   !true         // false
   true && false // false
   ```
3. **При проверке условий (`if`, `while`, тернарный оператор)**
   JS автоматически преобразует переданное значение к boolean:
   ```javascript
   if ("text") { ... } // "text" превращается в true
   if (0) { ... }      // 0 превращается в false
   ```
4. **При явном преобразовании**
   Через вызов функции `Boolean(value)`.

> 📌 **Итог:** Без типа `boolean` невозможно писать логику. Только благодаря ему код может реагировать на ситуацию, принимать решения и выполнять разные ветки инструкций.

## 2. Операторы сравнения
Операторы сравнения — это специальные символы, которые сравнивают два значения и возвращают результат в виде булевого значения (`true` или `false`). Без них невозможно написать условия, циклы или фильтрацию данных.

Сравнения в JS делятся на два важных типа:
1. Обычные сравнения величин (больше/меньше)
2. Сравнение на равенство (с тонкими нюансами)

### 2.1 Обычные сравнения
- `a > b` и `a < b` — строго больше / строго меньше
- `a >= b` и `a <= b` — больше или равно / меньше или равно

**Простые примеры:**
```javascript
console.log("10" > 2); // true (строка "10" превращается в число 10)
console.log("abc" > 2); // false (если один из операндов становится NaN, результат всегда false)
```

> ⚠️ **ВАЖНО: Строки сравниваются НЕ как числа!**
> Если оба операнда — строки, сравнение происходит посимвольно в алфавитном порядке на основе их **Unicode-кодов**.
> Unicode — это международный стандарт, который присваивает уникальный числовой код каждому символу (буквам, цифрам, эмодзи).
> ```javascript
> console.log("2" > "10"); // true (потому что "2" сравнивается с "1", а код "2" больше)
> console.log("a" > "b");  // false
> ```

**Как узнать Unicode-код символа:** `"строка".charCodeAt(index)`
```javascript
console.log("hello".charCodeAt(0)); // h -> 104
console.log("hello".charCodeAt(3)); // l -> 108
console.log("h" > "l");             // false (104 не больше 108)
```

**Примеры строковых сравнений:**
- `"яблоко" > "груша"` — сравнение идет посимвольно (первые буквы `я` и `г`). 
- Если первые буквы равны, сравниваются вторые. 
- Если все символы совпадают, но одна строка длиннее, то более длинная строка считается большей (`"кот" < "котик"` → `true`).

### 2.2 Сравнение на равенство
**Нестрогое равенство / неравенство (`==` и `!=`)**
Сравнивает значения с автоматическим приведением типов (если типы разные, JS пытается сделать их одинаковыми).
```javascript
5 == "5"          // true (строка становится числом)
true == 1         // true
false == 0        // true
"" == 0           // true
null == undefined // true (!!)
5 != "5"          // false
```
*Важно: Нестрогие равенства опасны непредсказуемым поведением, поэтому в современном JavaScript их используют редко.*

**Строгое равенство / неравенство (`===` и `!==`)**
Сравнивает и значения, и сами типы данных.
```javascript
5 === 5   // true
5 === "5" // false (разный тип данных)
5 !== 5   // false
5 !== "5" // true
```
> 🟦 **Правило:** Используйте только строгие операторы (`===` и `!==`). В профессиональном коде они применяются в 99% случаев.

## 3. Условия (`if` / `else if` / `else`)
Условия — это конструкция, которая позволяет выполнять определённый участок кода, только если заданное выражение истинно (`true`). Если условие ложное (`false`), блок кода пропускается.

### 3.1 Базовая форма: `if`
```javascript
if (age >= 18) {
    console.log("Вход разрешён");
}
```

### 3.2 Ветвление: `if ... else`
```javascript
if (password === "1234") {
    console.log("Пароль верный");
} else {
    console.log("Пароль неверный");
}
```

### 3.3 Множественные проверки: `if ... else if ... else`
Используется, когда нужно проверить несколько разных условий по очереди.
```javascript
if (score >= 90) {
    console.log("Отлично");
} else if (score >= 70) {
    console.log("Хорошо");
} else if (score >= 50) {
    console.log("Удовлетворительно");
} else {
    console.log("Плохо");
}
```

### 3.4 Вложенные условия
Нужны, когда решение зависит от нескольких последовательных проверок.
```javascript
let age = 20;
let country = "CZ";

if (age >= 18) {
    if (country === "CZ") {
        console.log("Доступ разрешён (возраст + страна)");
    } else {
        console.log("Возраст ок, но страна не подходит");
    }
} else {
    console.log("Недостаточно лет");
}
```

## 4. Логические операторы
Чтобы избежать огромного количества вложенных условий, используют логические операторы. Они объединяют или инвертируют условия. Результатом всегда будет `boolean`.

### 4.1 `&&` (AND — И)
Возвращает `true`, только если **оба** условия истинны. Если хотя бы одно `false` — результат `false`.
```javascript
if (age >= 18 && hasTicket) {
    console.log("Можно войти");
} else {
    console.log("Доступ запрещён");
}
```

### 4.2 `||` (OR — ИЛИ)
Возвращает `true`, если **хотя бы одно** условие истинно.
```javascript
let day = "Суббота";
if (day === "Суббота" || day === "Воскресенье") {
    console.log("Выходной");
}
```

### 4.3 `!` (NOT — НЕ)
Инвертирует логическое значение (`true` → `false`, `false` → `true`).
```javascript
let isRaining = false;
if (!isRaining) {
    console.log("Можно идти гулять");
}
```

### 4.4 Комбинирование логических операторов
Можно сочетать несколько операторов в одном условии (используйте скобки для приоритета):
```javascript
// Войти можно, если (взрослый + есть билет) ИЛИ (есть VIP-пас)
if ((age >= 18 && hasTicket) || vipPass) {
    console.log("Доступ разрешён");
}
```

### 4.5 Приемы для упрощения кода
Можно заменить короткий `if` на запись в одну строку:
```javascript
// Вместо этого:
if (age >= 18) {
    if (hasTicket) {
        console.log("OK");
    }
}

// Можно писать так:
if (age >= 18 && hasTicket) console.log("OK");
```

## 5. Тернарный оператор
Тернарный оператор — это короткая запись простого условия `if...else` в одну строку.

**Синтаксис:**
`условие ? значение_если_true : значение_если_false`

**Пример:**
```javascript
let age = 18;
// Вместо 5 строк кода if...else:
let result = age >= 18 ? "Можно войти" : "Доступ запрещён";
console.log(result);
```

**Особенности тернарного оператора:**
1. Можно сразу выводить в консоль: 
   `console.log(age >= 18 ? "Adult" : "Child");`
2. Удобно использовать для динамического HTML (в шаблонных строках):
   ```javascript
   document.body.innerHTML = `<h1>${age >= 18 ? "Добро пожаловать" : "Вход запрещён"}</h1>`;
   ```
3. **Не используйте**, если логика слишком сложная (много вложенностей), так как код станет нечитаемым. Идеально подходит для простых условий и присвоения значений.

## 💻 Практические задания

**1. Проверка возраста**
Просите пользователя ввести свой возраст, если ему больше или равано 18 віводим сообщение, что допуск разрещён

**2. Проверка чётности числа**
Пользователь вводит число и мы проверяем его чётное оно или нет

**3. Больше / меньше / равно**
 Сравниваем два числа которые пользователь вводит с клавиатуры
 
**4. Проверка логина и пароля**
- обьявляем две переменные которых зраняии в себе логин и пароль;
- просим пользователя по очереди ввести логин и пароль, если всё совпадает то вход разрещён

**5. Определение сезона**
Пользователь вводит номер месяйа от 1 до 12 и программа выводит ему название сезона в соответсвии к какому сезону относиться этот месяц

**6. Делится ли число на 3 и 5 одновременно**
Проверяем делиться ли введённое число пользователем одновременно на 3 и на 5

**7. Проверка длины строки**
Проверяем строку и віводим сообщение короткая если количество символов меньше 5, нормальная - от 5 до 15 и длинная - больше 15

**8. Проверка диапазона (от 10 до 20)**
Проверка лежит ли введённок число в диапазоне от 10 до 20

**9. Вложенные условия: кинотеатр**
Попросите пользователя ввести возраст.
- Если возраст < 16 → доступ запрещён.
- Если возраст от 16 до 18 → доступ только с родителями.
- Если 18 и больше → доступ разрешён.

**10. Погода и температура**
Пользователь вводит погоду (`sunny`, `cloudy`, `rain`) и температуру.
- Если (`sunny` или `cloudy`) И температура выше 15 — вывести «Можно гулять».
- Иначе — «Лучше остаться дома».

**11. Проверка пробела в строке**
Пользователь вводит текст.
- Если строка содержит пробел — вывести «Введено несколько слов».
- Иначе — «Одно слово».

**12. Тернарный оператор: скидка**
Пользователь вводит сумму покупки.
- Если сумма больше 1000 → скидка 10%, иначе 0%.
- Вывести итоговую сумму (обязательно использовать тернарный оператор).

**13. Оценка по баллам**
Пользователь вводит число от 0 до 100. Вывести:
- 90–100 → A
- 70–89 → B
- 50–69 → C
- меньше 50 → F

**14. Форматирование имени**
Пользователь вводит имя.
- Если имя начинается с заглавной буквы — оставить как есть.
- Если с маленькой — программно это исправить.
- Вывести исправленное имя на экран.

**15. Продвинутый тернарный оператор**
Пользователь вводит возраст и видит результат (использовать цепочку тернарных операторов):
- до 12 — ребёнок
- до 18 — подросток
- до 60 — взрослый
- старше 60 — пенсионер

**16. Строка в число с проверкой на NaN**
Дана строка, которую нужно перевести в число. Если строка не перевелась (результат `NaN`) — вернуть `null`. 
*(Подсказка: вспомните прошлую лекцию — почему нельзя использовать обычное сравнение с `NaN`, и примените правильный метод проверки).*
