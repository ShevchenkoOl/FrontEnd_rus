# Лекция 1: Введение в JavaScript

## 1. Что такое программирование?
**Программирование** — это процесс создания инструкций для компьютера. Эти инструкции называются программой, и они позволяют компьютеру выполнять задачи: от простых вычислений до сложных веб-приложений.

**Зачем нужно программирование:**
- автоматизировать процессы
- обрабатывать информацию
- создавать сайты, игры, приложения
- управлять устройствами и технологиями

**Как это работает?**
Программы пишутся на специальных языках — языках программирования. Компьютер понимает только двоичный код (0 и 1), поэтому язык программирования — это удобная форма для людей, которая затем переводится в машинный код.

---

## 2. Что такое JavaScript?
**JavaScript (JS)** — это язык программирования, который изначально был создан для оживления веб-страниц. Сегодня это один из самых популярных языков в мире, используемый как в браузерах, так и на сервере.

**Основные особенности JavaScript:**
- Работает прямо в браузере (Chrome, Firefox, Safari и др.).
- Позволяет динамически изменять страницу: анимации, обработка кликов, формы, меню и т.д.
- Использует модель событий (клики, ввод, прокрутка).
- Является языком высокого уровня.
- Имеет огромную экосистему библиотек и фреймворков (React, Vue, Node.js, React Native и др.).

---

## 3. Как появился JavaScript? — Краткая история

> 📌 **1995 год — Создание**
> - **Компания:** Netscape
> - **Разработчик:** Брендан Айх (Brendan Eich)
> - **Время разработки:** 10 дней (!)
> - **Первое название:** Mocha, затем LiveScript
> - **Окончательное имя:** JavaScript *(название выбрали в маркетинговых целях — тогда язык Java был очень популярен, и компании хотелось привлечь внимание)*.

**Задачи, для которых первоначально создавался JS:**
- добавить интерактивность веб-страницам
- дать браузерам возможность выполнять код
- позволить пользователям взаимодействовать с сайтом без перезагрузки страницы

> 📌 **2009 год — Появление Node.js**
> Появился новый инструмент, который позволил запускать JavaScript не только в браузере, но и на сервере. Благодаря этому JS стал полнофункциональным языком для backend.

> 📌 **2015 год — Революция стандарта ES6**
> Выход стандарта **ES6 (ECMAScript 2015)** полностью обновил язык. Появились:
> - `let` и `const`
> - стрелочные функции
> - классы
> - модули
> - промисы и множество других новых возможностей

Сегодня большинство современных проектов опираются на синтаксис ES6+.

## 4. Подключение JavaScript
JavaScript активно используется вместе с HTML. Чтобы подключить скрипт к HTML-документу, необходимо использовать тег `<script>` с атрибутом `src`, в котором указывается путь к файлу со скриптом.

**Пример:**
```html
<script src="app.js"></script>

```

## 5. Переменные и типы данных

### 5.1 Переменные

**Переменная** — это именованное место в памяти, в котором хранится какое-то значение, чтобы мы могли использовать его позже. Переменные состоят из идентификатора (имени) и области памяти. Переменную можно представить как коробку с названием, внутри которой лежит значение.

**Общий формат записи:**
`<ключевое_слово> <имя_переменной> = <значение>`

**Пример:**

```javascript
let userName = "Alex";

```

> ⚠️ **ВАЖНО!** В JavaScript точка с запятой `;` не является обязательной, но лучше её ставить, потому что:
> * это повышает читаемость
> * исключает редкие, но неприятные ошибки
> * так принято в большинстве стилей кода (например, в крупных компаниях)
> Главное — быть последовательным.
> 
> 

#### 5.1.1 Ключевые слова

В JavaScript есть три способа объявить переменную: `let`, `const`, `var`. Только два из них — современные.

**1. `let**` — современный способ объявления переменной. Используется в том случае, когда значение переменной должно меняться со временем.

```javascript
let count = 0;
count = 1;

```

*Особенности `let`:*

* можно перезаписывать значение
* нельзя объявлять одну и ту же переменную дважды
* имеет блочную область видимости (работает только внутри фигурных скобок `{}`, будь то циклы, условия или функции).

Служебное слово `let` используется только один раз при объявлении переменной, дальше мы работаем без него:

```javascript
let a = 15;
a = 18; // Перезаписали значение
let a = 21; // ❌ Ошибка! Переменная уже объявлена

```

**2. `const**` — используется для значений, которые не должны изменяться (константы).

```javascript
const pi = 3.14;
pi = 4; // ❌ Ошибка — значение менять нельзя

```

*Особенности `const`:*

* значение нельзя изменить
* обязательно нужно указать начальное значение при объявлении
* имеет блочную область видимости

> **Примечание:** Переменные, названия которых пишутся большими буквами (капсом) — это константы, значения которых известны заранее и никогда не меняются. Это визуально выделяет важные значения.
> ```javascript
> const PI = 3.14;
> const API_URL = "[https://example.com](https://example.com)";
> const MAX_USERS = 1000;
> 
> ```
> 
> 

**3. `var**` — старый способ объявления переменных. Сейчас использовать его **НЕ рекомендуется**!
*Главные особенности (и недостатки):*

* имеет функциональную область видимости, а не блочную
* допускает повторное объявление одной и той же переменной
* ведёт себя непредсказуемо из-за эффекта «всплытия» (hoisting)

#### 5.1.2 Идентификаторы (Имена переменных)

Идентификатор — это имя переменной, функции или класса.

**Правила создания имён:**

* **Первый символ** может быть: латинской буквой (`a-z`, `A-Z`), символом подчёркивания (`_`) или знаком доллара (`$`).
* **Последующие символы** могут быть: буквами, цифрами (`0–9`), подчёркиванием (`_`), знаком доллара (`$`).
* Идентификаторы **чувствительны к регистру**: `user`, `User` и `usEr` — это разные переменные.

**Специальные символы в практике:**
Почти во всех языках семейства C переменные могут начинаться и заканчиваться на `_` или `$`. В реальной практике они несут определённый смысл:

* Приватность: `_password`
* Внутренние переменные функции (используется только внутри): `let _cache = {}`
* Игнорируемые переменные: `const [_, second] = [10, 20];`
* Избегание конфликтов: `let delete_ = true;`
* Отличие аргумента от внешней переменной:
```javascript
let value = 10;
function calc(value_) {
    return value_ + value;
}

```


* Символ `$` часто используют в переменных, связанных с библиотекой jQuery.

**Стиль написания:**
В JavaScript используется нотация **camelCase** — это стандарт:

* первое слово пишется строчными буквами
* каждое следующее — с заглавной буквы
*Примеры:* `user`, `greetUser`, `getUserData`, `isActive`, `totalWorkerSalary`.

### 5.2 Вывод данных

Способы вывести результат работы кода:

* `console.log()` — выводит результат в консоль браузера. Идеально для отладки, не видно обычному пользователю.
* `alert()` — модальное окно с сообщением. Подходит для быстрых тестов, но редко используется в реальных проектах.
* `document.body.innerHTML` — добавляет содержимое непосредственно в HTML-код страницы.

**Примеры вывода на страницу:**

```javascript
document.body.innerHTML = "<h1>Hello World!</h1>";
document.body.innerHTML += "<h1>Hello World!</h1>" + "<button>Click me!</button>";

// Использование шаблонных строк (обратные кавычки ` `) — самый удобный способ:
document.body.innerHTML += `
    <h1>Hello World!</h1> 
    <button>Click me!</button>
`;

```

### 5.3 Типы данных

Тип данных — это вид информации, которая хранится в переменной. JavaScript различает типы, чтобы понимать, как с ними работать.

| Тип данных | Пример | Описание |
| --- | --- | --- |
| **Number** | `42`, `3.14` | Числа |
| **String** | `"Hello"` | Текст (строки) |
| **Boolean** | `true`, `false` | Логические значения (истина/ложь) |
| **Null** | `null` | Пусто, специально заданное «ничего» |
| **Undefined** | `undefined` | Переменная объявлена, но не имеет значения |
| **Object** | `{name: "Alex"}` | Объект |
| **Array** | `[1, 2, 3]` | Список значений (массив) |
| **Function** | `function() {}` | Функция |

Чтобы проверить, какой тип данных хранится в переменной, используется оператор `typeof`:

```javascript
console.log(typeof "Hello"); // Выведет "string"

```

**Важное о синтаксисе:**

* Текст всегда пишется в кавычках (`"Alex"`, `'Alex'`).
* Числа пишутся без кавычек (`5`, `8.7`). Если число дробное, используется точка.

## 6. Взаимодействие с пользователем

**1. `confirm()**`
Выводит модальное окно с сообщением и двумя кнопками: *Ok* и *Cancel*.

* При нажатии *Ok* возвращает `true`
* При нажатии *Cancel* возвращает `false`

```javascript
// Просим клиента подтвердить бронирование и сохраняем результат
const isComing = confirm("Пожалуйста, подтвердите бронирование отеля");
console.log(isComing);

```

**2. `prompt()**`
Выводит модальное окно с полем для ввода текста и кнопками *Ok* и *Cancel*.

* При нажатии *Ok* возвращает введённый пользователем текст
* При нажатии *Cancel* возвращает `null`

```javascript
// Спрашиваем название отеля
const hotelName = prompt("Пожалуйста, введите название желаемого отеля");
console.log(hotelName);

```

## 7. Арифметические операции

| Оператор | Описание | Пример |
| --- | --- | --- |
| `+` | сложение / конкатенация | `5 + 3 = 8` <br>

<br> `"Hi" + "!" = "Hi!"` |
| `-` | вычитание | `10 - 4 = 6` |
| `*` | умножение | `6 * 3 = 18` |
| `/` | деление | `10 / 2 = 5` |
| `%` | остаток от деления | `10 % 3 = 1` |
| `**` | возведение в степень | `2 ** 3 = 8` |

Знаки называются **операторами**, а значения, с которыми они работают — **операндами**.

**Как работают операторы:**
1️⃣ **Оператор `+` (сложение / конкатенация)**

* Если хотя бы один операнд — строка, выполняется объединение строк.
* Если оба — числа, выполняется сложение.

```javascript
console.log("5" + 3);       // "53" (строка)
console.log("Hello" + true);// "Hellotrue" (строка)
console.log(5 + 3);         // 8 (число)

```

2️⃣ **Остальные операторы (`-`, `*`, `/`, `%`, `**`)**
JavaScript автоматически пытается превратить строки в числа.

* Если получается → считает как числа.
* Если строку нельзя превратить в число → выдает `NaN` (Not a Number).

```javascript
console.log("10" - "2"); // 8 (числа)
console.log("5" * 3);    // 15 (числа)
console.log("abc" * 3);  // NaN (ошибка вычисления)

```

### Арифметические сокращения

| Оператор | Полная форма | Пример | Результат |
| --- | --- | --- | --- |
| `+=` | `i = i + n` | `i = 5; i += 3` | `i = 8` |
| `-=` | `i = i - n` | `i = 10; i -= 4` | `i = 6` |
| `*=` | `i = i * n` | `i = 3; i *= 5` | `i = 15` |
| `/=` | `i = i / n` | `i = 20; i /= 4` | `i = 5` |
| `%=` | `i = i % n` | `i = 17; i %= 5` | `i = 2` |
| `**=` | `i = i ** n` | `i = 2; i **= 3` | `i = 8` |
| `++` | `i = i + 1` | `i = 5; i++` | `i = 6` |
| `--` | `i = i - 1` | `i = 5; i--` | `i = 4` |
