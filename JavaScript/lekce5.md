# Лекция 5: Структуры данных: Массивы и Объекты

На предыдущих занятиях мы познакомились с базовыми типами данных — строками и числами. Но для реального программирования этого недостаточно. Нам нужно уметь хранить списки данных и работать со структурированной информацией. Именно для этого в JavaScript существуют массивы и объекты.

---

## 1. Массивы (Array)

**Массив** — это структура данных для хранения коллекции значений. В отличие от строк и чисел, массив не является примитивом. Это сложный (ссылочный) тип данных, который позволяет хранить набор упорядоченных значений (список).

Массив объявляется как обычная переменная, а его значение задаётся в квадратных скобках `[]` (литерал массива). Внутри может быть любое количество элементов любого типа данных, разделённых запятыми:
```javascript
const arr1 = ["apple", 12, true];
````
>**Примечание:** в JavaScript нет отдельно типа данных `array (массив)`, массив — это просто особый вид объекта.
>```javascript
>typeof["apple", 12, true] // "object"
>````
>Как тогда проверить массив?
>```javascript
>Array.isArray([1, 2]) // true
>typeof arr === "array" // ❌ такого не существует
>````

### 1.1 Доступ, изменение и длина

Доступ к отдельному элементу осуществляется по индексу (начиная с нуля):

```javascript
const arr1 = ["apple", 12, true];
//              0      1    2

console.log(arr1[0]); // "apple"
```

В отличие от строк, **элементы массива можно изменять**. Достаточно обратиться по индексу и присвоить новое значение:

```javascript
const clients = ["Mango", "Poly", "Ajax"];
clients[0] = "Kiwi";
clients[1] = "Pango";
console.log(clients); // ["Kiwi", "Pango", "Ajax"]
```

Количество элементов в массиве определяется свойством `length`. Это динамическая величина, которая меняется автоматически при добавлении или удалении элементов:

```javascript
console.log(clients.length); // 3

// Индекс последнего элемента всегда равен:
console.log(clients.length - 1); // 2
```

### 1.2 Разница между `const` и `let` в массивах

  * **`const`** — нельзя переназначить саму переменную, но **можно** менять содержимое массива (добавлять, удалять, изменять элементы).
    ```javascript
    const arr = [1, 2, 3];
    arr[0] = 100;   // ✔ можно
    arr.push(4);    // ✔ можно
    arr = [9, 9];   // ❌ ОШИБКА: нельзя переназначать константу
    ```
  * **`let`** — можно менять и содержимое массива, и переназначать переменную целиком.
    ```javascript
    let arr = [1, 2, 3];
    arr = [9, 9];   // ✔ можно (создана новая коллекция)
    ```

### 1.3 Методы для работы с массивами

  * **`split(delimiter)`** *(метод строк)* — преобразует строку в массив, разбивая её по разделителю.

    ```javascript
    const name = "Mango";
    console.log(name.split("")); // ["M", "a", "n", "g", "o"]

    const message = "JavaScript - это интересно";
    console.log(message.split(" ")); // ["JavaScript", "-", "это", "интересно"]
    ```

  * **`join(delimiter)`** — объединяет элементы массива в строку. Противоположность `split`.

    ```javascript
    const words = ["JavaScript", "это", "интересно"];
    console.log(words.join(""));  // "JavaScriptэтоинтересно"
    console.log(words.join(" ")); // "JavaScript это интересно"
    console.log(words.join("-")); // "JavaScript-это-интересно"
    ```

  * **`indexOf(value)`** — возвращает первый индекс искомого элемента. Если элемента нет, возвращает `-1`.

    ```javascript
    const clients = ["Mango", "Ajax", "Poly", "Kiwi"];
    console.log(clients.indexOf("Poly"));    // 2
    console.log(clients.indexOf("Monkong")); // -1
    ```

  * **`includes(value)`** — проверяет, есть ли элемент в массиве, возвращает `true` или `false`.

    ```javascript
    console.log(clients.includes("Poly")); // true
    ```

    > 💡 **Подсказка:** Можно проверять сразу несколько условий: `if (arr.includes(2) && arr.includes(3)) { ... }`

  * **Добавление элементов:**

      * **`push(...elements)`** — добавляет в **конец** массива (возвращает новую длину).
      * **`unshift(...elements)`** — добавляет в **начало** массива.

  * **Удаление элементов:**

      * **`pop()`** — удаляет **последний** элемент и возвращает его.
      * **`shift()`** — удаляет **первый** элемент и возвращает его.

  * **`slice(begin, end)`** — копирует часть массива от `begin` до `end` (не включая `end`). Не изменяет исходный массив\!

    ```javascript
    const arr = [1, 2, 3, 4, 5];
    console.log(arr.slice(1, 4)); // [2, 3, 4]
    console.log(arr.slice());     // [1, 2, 3, 4, 5] (полная копия)
    ```

  * **`splice(position, num, ...items)`** — **швейцарский нож**. Изменяет исходный массив (удаляет и/или вставляет элементы).

      * `position` — индекс, с которого начать.
      * `num` — сколько элементов удалить (можно `0`).
      * `...items` — что вставить на это место.

    <!-- end list -->

    ```javascript
    const arr = [1, 2, 3, 4, 5];
    const removed = arr.splice(1, 2); // Удаляем 2 элемента начиная с индекса 1
    // removed = [2, 3], arr = [1, 4, 5]

    arr.splice(1, 0, 9, 10); // Вставка без удаления
    // arr = [1, 9, 10, 4, 5]
    ```

  * **`concat()`** — объединяет массивы. Не изменяет исходные, возвращает новый массив.

    ```javascript
    const oldC = ["Mango", "Ajax"];
    const newC = ["Monkong", "Singu"];
    console.log(oldC.concat(newC)); // ["Mango", "Ajax", "Monkong", "Singu"]
    ```

### 1.4 Перебор массивов

  * **`for`** — классический цикл. Нужен, когда важен индекс, нужно идти с шагом (например, `i+=2`), с конца в начало, или прерывать цикл (`break`/`continue`).
    ```javascript
    for (let i = 0; i < arr.length; i++) {
        console.log(i, arr[i]);
    }
    ```
  * **`for...of`** — современный способ. Идеален, когда нужны только сами значения, а индекс не важен. Код короче и чище.
    ```javascript
    for (const value of arr) {
        console.log(value);
    }
    ```

## 2\. Объекты (Object)

**Объект** — это сложный тип данных, который хранит набор свойств в виде пар **«ключ: значение»**.

  * Ключ (имя свойства) — всегда строка.
  * Значение — любой тип данных (строка, число, массив, другой объект).

Объект объявляется в фигурных скобках `{}` (литерал объекта):

```javascript
const user = {
    name: "Jacques",
    tag: "jgluke",
    stats: {
        followers: 5603,
        views: 4827
    }
};
```
>**Примечание:** выше мы расмотрели, что массив это особый вид обьекта, тогда возникает вопрос, где ключи у массива?
>Индекс едемента массива это и есть его ключ:
> ```javascript
>const arr = ["a", "b", "c"];
> // на самом деле это:
>{
  >0: "a",
  >1: "b",
  >2: "c"
>}
>```
### 2.1 Доступ к свойствам

1.  **Через точку (`object.property`)** — самый частый способ. Используется, когда имя ключа известно заранее и не содержит пробелов или спецсимволов.
    ```javascript
    console.log(user.name); // "Jacques"
    console.log(user.city); // undefined (свойства нет)
    ```
2.  **Квадратные скобки (`object["property"]`)** — используется, если ключ содержит пробелы, дефисы или если имя ключа хранится в переменной:
    ```javascript
    let key = "tag";
    console.log(user[key]); // "jgluke"
    ```

### 2.2 Изменение и удаление свойств

```javascript
// Добавление или изменение
user.age = 26; 

// Удаление
delete user.tag; 
```

>*Правила `const` и `let` здесь работают точно так же, как в массивах\! Вы не можете переопределить константу `user = {}`, но можете менять её внутренние свойства `user.age = 30`.*

### 2.3 Методы перебора объектов

  * **Цикл `for...in`** — перебирает ключи объекта.
    ```javascript
    for (const key in user) {
        console.log(key);       // имя ключа
        console.log(user[key]); // значение
    }
    ```
  * **`Object.keys(obj)`** — возвращает массив ключей `["name", "tag", "stats"]`.
  * **`Object.values(obj)`** — возвращает массив значений `["Jacques", "jgluke", { ... }]`.
  * **`Object.entries(obj)`** — возвращает массив массивов `[["name", "Jacques"], ...]`.

## 3\. Деструктуризация

При разработке данные часто приходят в виде больших объектов. Чтобы не писать каждый раз `user.name`, `user.age`, мы можем «распаковать» объект в отдельные переменные.

### 3.1 Деструктуризация объектов

```javascript
const user = { name: "Alex", age: 26, email: "alex@test.com" };

// Извлекаем свойства в переменные (можно задать значение по умолчанию)
const { name, age, city = "Prague" } = user;

console.log(name); // "Alex"
console.log(city); // "Prague"
```

**Глубокая деструктуризация** (для вложенных объектов):

```javascript
const profile = { 
    tag: "jgluke", 
    stats: { followers: 5000, likes: 1300 } 
};

const { tag, stats: { followers, likes = 0 } } = profile;
console.log(followers); // 5000
```

### 3.2 Деструктуризация массивов

Работает по порядку элементов. Ненужные элементы можно пропускать запятыми.

```javascript
const numbers = [10, 20, 30, 40];
const [first, , third] = numbers;

console.log(first); // 10
console.log(third); // 30
```

### 3.3 Деструктуризация в циклах

Очень удобно при переборе массива объектов:

```javascript
const books = [
    { title: "Dune", rating: 9.2 },
    { title: "1984", rating: 8.8 }
];

for (const { title, rating } of books) {
    console.log(`Книга: ${title}, Рейтинг: ${rating}`);
}
```

## 💡 Шпаргалка: Почему `typeof null` возвращает "object"?

Это известный баг, который существует с самого создания JavaScript в 1995 году\!
**Техническая причина:** В первой версии JS значения хранились с метками типа. Объекты имели метку `000`, а `null` был представлен как NULL pointer (все нули `0x00`). Поэтому `typeof` ошибочно посчитал `null` объектом.

  * `null` — это примитивный тип данных ("намеренное отсутствие значения").
  * `null` **НЕ** является объектом.
  * Этот баг не исправляют, чтобы не сломать миллионы старых сайтов.

**Как правильно проверять на null:**

```javascript
if (value === null) { ... } // Строгое сравнение!
```

**7. Увеличение в 2 раза** С помощью цикла умножь каждое число массива `[2, 4, 6]` на 2 и положи в новый массив.

### Задачи со звёздочкой✨:

**12⭐. Первое пропущенное положительное число** Дан массив чисел. Найди наименьшее положительное целое число (больше нуля), которого нет в массиве. Необходимо найти наименьшее положительное целое число (большн нуля), которое не содержится в этом массиве.
Числа в массиве могут быть:
    * положительными,
    * отрицательными,
    * нулём,
    * расположенными в произвольном порядке.
> Пример: </br>
> `arr = [1, 2, 3, 5, 4, 8, 9] // 6` </br>
> `arr = [-2, 0, 1, 3] // 2`

<details>
  <summary>💡 Посмотреть решение</summary>
  
```javascript
const arr = [1, 2, 3, 5, 4, 8, 9]; 

let num = 1;
// Пока число есть в массиве, увеличиваем его на 1
while (arr.includes(num)) {
    num++;
}

console.log(`Пропущенное число: ${num}`); // 6
```
</details>

**13⭐. Городской автобус** Дан массив остановок `[[вход, выход], [вход, выход]]`. в котором каждый елемент массива это ещё один массив в котором первый елемент это пассажиры которые зашли и второй элемент это пасажиры которые вышли 
То есть, на каждой остановке в автобус заходят `el[0]` человек и выходят `el[1]` человек.
Нужно определить, сколько пассажиров останется в автобусе после последней остановки.

>Пример: </br>
>`[[10,0],[3,5],[5,8]] // 5` </br>
>`[[3,0],[9,1],[4,10],[12,2],[6,1],[7,10]] // 17` </br>
>`[[3,0],[9,1],[4,8],[12,2],[6,1],[7,8]] // 21` </br>
>`[[0,0]]` // 0</br>

<details>
  <summary>💡 Посмотреть решение</summary>
  
```javascript
const bus = [[10,0], [3,5], [5,8]];
let passengers = 0;

for (const stop of bus) {
    // Прибавляем вошедших [0] и отнимаем вышедших [1]
    passengers = passengers + stop[0] - stop[1];
}

console.log(`В автобусе осталось: ${passengers}`); // 5
```
</details>
