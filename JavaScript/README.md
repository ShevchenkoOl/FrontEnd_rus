# 🎓 Завершающий проект по JavaScript

Студентам предлагается на выбор один из двух вариантов итоговой работы:

## Вариант 1: Поиск изображений (Pixabay API)
Создание сервиса для поиска и просмотра фотографий в реальном времени.
* **Технологии:** Fetch/Axios, Модальные окна, Пагинация, Спиннеры.
* **API:** [Pixabay Documentation](https://pixabay.com/api/docs/)

## Вариант 2: Апгрейд проекта HTML & CSS
Интеграция сложной логики в уже существующий проект первого модуля.
* **Обязательно:** Работа с DOM, минимум 3 типа событий, валидация форм, модалки на JS, использование LocalStorage.

---
### 🛠 Требования к коду
1. Использование современных методов перебора массивов (`map`, `filter` и др.).
2. Чистота кода и отсутствие ошибок в консоли.
3. Разделение логики на модули (где применимо).
