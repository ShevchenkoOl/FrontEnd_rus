# 🛠 Основы терминала (Command Line Interface - CLI) и Linux для Front-end разработчика

Как фронтенд-разработчик, большую часть времени ты будешь проводить в редакторе кода (VS Code) и **терминале**. Терминал — это способ общаться с компьютером напрямую с помощью текстовых команд, без использования мышки и графического интерфейса.

## 🌍 Почему Linux, если у меня Windows?
Большинство современных веб-инструментов, серверов и библиотек (включая экосистему [Node.js](https://nodejs.org/) изначально создаются для **Linux**. 

* **Windows** — отличная система для интерфейса и повседневных задач.
* **Linux** — индустриальный стандарт для веб-разработки и серверов. 
* **WSL (Windows Subsystem for Linux)** — это инструмент, который позволяет запускать полноценный Linux (например, Ubuntu или Debian) прямо внутри твоего Windows. Тебе не нужно устанавливать вторую систему — ты просто открываешь терминал и работаешь в среде Linux, находясь в привычном Windows.

> **Важно:** Команды в терминале Windows (PowerShell) и Linux (Bash) могут выглядеть одинаково (например, `ls`), но работают они по-разному. Для веб-разработки мы всегда стараемся использовать окружение Linux/WSL.

## 🧭 Навигация: Как перемещаться по папкам

В терминале ты всегда находишься в какой-то конкретной папке. Эти команды помогут понять, где ты, и перейти туда, куда нужно.

| Команда | Описание |
| :--- | :--- |
| `pwd` | **«Где я?»** Выводит полный путь к текущей папке. |
| `ls` | **Показать содержимое.** Выводит список файлов и папок. |
| `ls -la` | Показать **всё**, включая скрытые файлы (например, `.env` или `.gitignore`), их размер и права. |
| `cd <имя_папки>` | **Войти в папку.** (Например: `cd frontend-project`). |
| `cd ..` | **Выйти назад** на один уровень (в папку-родитель). |
| `cd ~` | Быстро вернуться в свою **домашнюю** директорию. |

*💡 Совет: Если в названии папки есть пробелы, бери её в кавычки: `cd "My Project"`.*

## 📁 Работа с файлами и директориями

Создание компонентов, удаление старых билдов и перемещение картинок — всё это можно делать без проводника.

| Команда | Описание |
| :--- | :--- |
| `mkdir <имя>` | **Создать новую папку** (Make Directory). |
| `touch <имя_файла>` | **Создать пустой файл** (Например: `touch index.html`). |
| `cat <имя_файла>` | Быстро **посмотреть содержимое** файла прямо в терминале. |
| `cp <что> <куда>` | **Скопировать** файл. |
| `mv <что> <куда>` | **Переместить** (или переименовать) файл/папку. |
| `rm <файл>` | **Удалить файл.** |
| `rm -rf <папка>` | ⚠️ **Удалить папку со всем содержимым.** Осторожно: Корзины в Linux нет, удаляется навсегда! |

## 🟢 Работа с Node.js (NVM)

Для запуска проектов на React, Vue или Angular тебе нужен Node.js. В Linux его лучше всего устанавливать через **NVM (Node Version Manager)**, чтобы легко переключаться между версиями для разных проектов.

| Команда | Описание |
| :--- | :--- |
| `nvm install 20` | Установить конкретную версию Node.js (например, 20-ю). |
| `nvm use 20` | Переключить текущий терминал на 20-ю версию. |
| `nvm ls` | Посмотреть список всех установленных у тебя версий. |
| `nvm alias default 20`| Сделать 20-ю версию версией по умолчанию. |
| `node -v` | Проверить, какая версия Node.js сейчас активна. |

## 🚀 Как установить WSL

Официальное руководство от Microsoft:
🔗 [Установка WSL (Microsoft Learn)](https://learn.microsoft.com/ru-ru/windows/wsl/install)

**Самый быстрый способ установки для Windows 10/11:**
1. Открой **PowerShell** от имени администратора.
2. Введи всего одну команду и нажми Enter:
   ```powershell
   wsl --install
   ```
3. Перезагрузи компьютер. </br>
Эта команда автоматически скачает и установит подсистему Linux, а также установит дистрибутив Ubuntu по умолчанию.

## 🔗 Интеграция WSL и Windows

Поскольку WSL — это Linux внутри Windows, у них разные файловые системы (разные способы хранения файлов). Файлы Linux изолированы от Windows для скорости и безопасности.

**Как работать с файлами:**
1. **Из Windows в Linux:** Открой проводник Windows и введи в адресную строку `\\wsl$\`. Ты увидишь все свои папки Linux.
2. **Из Linux в Windows:** Твои диски Windows (C, D) лежат в Linux в папке `/mnt`. Чтобы зайти на диск D из терминала Linux, напиши: `cd /mnt/d/`.

**Как открыть проект в VS Code из WSL:**
* Зайди в папку с проектом в терминале Linux.
* Напиши команду: `code .`
* VS Code сам запустится в Windows, но будет подключен к твоему проекту внутри Linux.

## 🛠 Системные помощники

| Команда | Описание |
| :--- | :--- |
| `clear` | **Очистить экран** терминала, если стало слишком много текста. |
| `history` | Показать список всех команд, которые ты вводил ранее. |
| `sudo <команда>` | Выполнить команду **с правами администратора** (потребует ввод пароля). |
| `Ctrl + C` | **Остановить** любой зависший процесс (например, выключить локальный сервер разработки). |
